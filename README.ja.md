# Lumina

**フォルダーに散らばった写真・動画・参考画像を、探しやすく、整理しやすく。**

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

<img src="apps/desktop/renderer/public/lumina-album-icon-256.png" width="80" alt="Luminaのアルバムアイコン">

Luminaは、**Windows向けのローカル写真・動画管理アプリ**です。既存のフォルダーを追加すると、まとめて閲覧・検索し、タグやアルバムで整理できます。重複ファイルや似た写真の比較にも対応。アカウント登録は不要で、日常の整理はオフラインで行えます。

**正式版 1.0.0 · Windows 10 / 11 x64 · 中国語・英語・日本語**

[インストーラー・ZIP版をダウンロード](https://github.com/710765989/Lumina/releases/tag/v1.0.0) · [詳しい使い方：中国語](docs/user-guide.md) · [不具合を報告](https://github.com/710765989/Lumina/issues)

## どんなところが便利？

**フォルダー構成を保ったまま、別の探し方を追加。** すべての写真を専用ライブラリへ移す必要はありません。ファイルの場所を記録し、表示用キャッシュを作成します。元のファイルは選択したフォルダーに残ります。複数のフォルダーをまとめて見たり、タイムラインから特定の月へ移動したりできます。

**1枚の写真に複数の分類。分類のためのコピーは不要。** 海辺の写真に「旅行」「風景」「壁紙」を付けたり、複数のアルバムに入れたりしても、参照するのは同じファイルです。タグは最大5階層と複数の親タグに対応し、増えていく参考資料も整理できます。

**繰り返す整理はルールに任せる。** 「旅行」と「風景」を含むスマートアルバムを作れば、後から同じ条件のタグを付けた写真も自動で表示されます。ディレクトリタグを設定すると、フォルダーとその配下のメディアに分類を引き継ぎ、後から追加されたファイルにも適用できます。

**削除前に見比べて、選んだ素材をそのまま使う。** 完全に同じファイルと、見た目が似ている写真を分けて確認できます。左右で比較して残すものを選び、削除前に件数と容量を確認。選んだファイルは、ファイルのドロップに対応する外部アプリへドラッグして渡せます。

## こんなときに

| 困っていること | Luminaでできること |
| --- | --- |
| 年別・機器別・バックアップ先に写真が分散している | フォルダーを追加して、日付順にまとめて閲覧 |
| 同じ画像を「人物」と「構図の参考」の両方に分類したい | 複数のタグで、1つの元ファイルを整理 |
| 毎回同じ種類の写真を探している | タグ条件で自動更新するスマートアルバムを作成 |
| 書き出し画像・バックアップ・連写が混在している | 重複・類似検出で比較してから削除対象を選択 |
| 見つけた画像を別のアプリで使いたい | 外へドラッグ、またはエクスプローラーで表示 |
| 写真をクラウドに送らず整理したい | ローカルの索引とキャッシュで管理。クラウドアカウント不要 |

## 操作の例

**サムネイルの大きさと表示を切り替える：** 標準・時系列・ウォーターフォール・一覧の4種類。スライダーや `Ctrl` + マウスホイールで大きさを変えられます。アニメーションは設定で無効にできます。

![サムネイルの大きさと表示形式の切り替え](docs/images/gallery-browsing.gif)

**条件を重ねて探す：** タグを選んでから、ファイル名や形式を追加。タグの除外や、タグなしのメディア検索も可能です。日本語では漢字・かな・ローマ字で検索でき、例えば `shashin` で「写真」が見つかります。漢字やカタカナのタグ名から、ひらがなの別名を自動入力できます。別名は編集可能です。

![タグとファイル名を組み合わせた検索](docs/images/tag-search.gif)

動画は中国語表示と独立したサンプルライブラリで収録しています。圧縮したGIFのため、アプリの実際のフレームレートや、すべての環境での性能を示すものではありません。

## まずは5分で試す

1. **フォルダーを追加：** 一般設定のディレクトリ設定から、既存の写真・動画フォルダーを選びます。
2. **キャッシュ先を確認：** 初回スキャン前に保存先を選択します。空き容量に余裕があればSSDも選択肢です。
3. **閲覧：** ライブラリでタイムライン・検索・右クリックメニューを試します。
4. **少しだけ分類：** 数枚にタグを付け、通常のアルバムやスマートアルバムを作ります。
5. **進捗を確認：** 大量の処理は、右上のタスクボタンや設定のタスク状態から確認できます。

**既存フォルダーの追加は主に索引の作成、インポートは指定先へのファイルコピーです。** インポートはドラッグ＆ドロップ、貼り付け、複数フォルダーに対応し、同名ファイルがある場合は確認します。

## どれをダウンロードする？

[1.0.0のリリースページ](https://github.com/710765989/Lumina/releases/tag/v1.0.0)で選んでください。

| ファイル | 用途 | 使い方 |
| --- | --- | --- |
| `Lumina-1.0.0-Setup-x64.exe` | Windowsインストーラー | ウィザードに従い、デスクトップやスタートメニューから起動 |
| `Lumina-1.0.0-win-x64.zip` | インストール不要版 | 全体を展開して `Lumina.exe` を起動 |
| `Lumina-1.0.0-source.zip` | コードの閲覧・ビルド | ソースコード。アプリとして直接実行はできません |
| `SHA256SUMS.txt` | ダウンロードの確認 | SHA-256の値を照合 |

利用時にNode.js、Python、FFmpegを別途インストールする必要はありません。インストール時に言語を選べ、一般設定からも変更できます。日本語・英語のショートカット名は **Lumina**、中国語は **光匣 Lumina** です。

配布ファイルはコード署名されていないため、Windowsに「不明な発行元」と表示される場合があります。入手元を確認し、PowerShellの `Get-FileHash .\Lumina-1.0.0-Setup-x64.exe -Algorithm SHA256` でファイルを照合できます。

## ファイルとデータについて

- **元ファイル・整理情報・キャッシュは別のものです。** 元ファイルは選んだフォルダーに、タグやアルバム・索引はローカルのデータベースに保存します。サムネイルや互換プレビューはキャッシュです。キャッシュは再生成できますが、整理データベースはバックアップが必要です。
- **ローカル管理はバックアップの代わりにはなりません。** 元写真の自動バックアップや、追加時の重複ファイル自動削除は行いません。
- **非表示は暗号化ではありません。** アプリ内の非表示と任意のWindows隠し属性は、パスワードによるアクセス制限ではありません。
- **類似写真の削除は自分で判断します。** 通常のアルバムから外す操作は所属だけを変更し、メディアの削除はファイル操作になります。完全削除は元に戻せません。
- **拡張子だけでは再生可否が決まりません。** 一部のHEIF・AVI・特殊なコーデックは非対応、または互換プレビューの準備に時間がかかる場合があります。外部ビューアー・プレーヤーも利用できます。WebMは動画として扱います。

実際のデータベースとキャッシュの場所は、一般設定のキャッシュ設定で確認してください。ZIP版もWindowsユーザーのアプリデータ領域を使用するため、**プログラムのフォルダーをコピーするだけでは整理情報全体を移行できません**。更新前にアプリを閉じ、元ファイルとユーザーデータをバックアップしてください。アンインストールでは通常、ユーザーデータベースと外部キャッシュを保持します。インストール先の中にあるキャッシュは、そのフォルダーとともに削除される場合があります。[詳しい説明：中国語](docs/user-guide.md)

Luminaはローカルの閲覧・整理に特化しています。高度な写真編集、クラウドバックアップ、チーム共同作業、暗号化保管庫、顔認識、画像内容の意味検索は提供していません。日本語辞書は読みを補うもので、**タグを別の言語へ翻訳するものではありません**。性能はストレージ・コーデック・件数・再生設定により異なります。他アプリや別のPC、大規模な実データでの継続テストについては[検証記録：中国語](docs/m2-acceptance.md)を参照してください。

## コードを読む・自分でビルドする

Windows x64、Node.js 22.13以上、pnpm 11.25.0を使用します。ネイティブ依存関係のビルド済みファイルがない場合は、PythonとVisual Studio C++ Build Toolsも必要です。

```powershell
corepack enable
corepack prepare pnpm@11.25.0 --activate
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm --filter @lumina/desktop dev
```

ZIP版は `pnpm --filter @lumina/desktop package:zip`、インストーラーは `package:installer` で作成します。出力先は `apps/desktop/release/` です。初回ビルドは依存関係のダウンロードにネット接続が必要ですが、日常の利用はオフラインで行えます。リポジトリとソースZIPには、個人の写真・動画、データベース、キャッシュ、ログ、認証情報を含めません。
