# M2 .4.8.1 小补丁

日期：2026-10-20。基于 .4.8，数据库仍为 schema 8。

- 已添加目录的设置页直接读取索引，保留已知空目录。修改目录规则只后台整理已索引媒体；仅改名或保存相同设置不创建扫描/整理任务。新增规则路径只定向校验，不遍历整棵目录。首次添加仍预览并扫描；“重新读取目录”只更新预览，“重新扫描”负责同步文件变化。目录暂时离线、停用时也可修改已有规则。
- 媒体标签缩为 14px 单行，超出隐藏；卡片和悬停提示只使用中文名，完整文件名及全部标签保留在悬停提示。标签管理仍显示中英文名并支持双语、拼音首字母搜索。
- 暂停任务的列表和详情补上取消入口；目录整理取消同时取消已暂停的子扫描。取消保留已完成结果，不自动回退。
- 任务流水线新增“清理任务历史”：默认已完成/已取消，可另勾选失败记录；确认时冻结记录集合，执行时重新核对状态和实际工作线程，保留运行/等待/暂停以及仍在结束当前文件的任务。级联清理逐文件明细，不删除媒体、缓存、标签、相册。自动7天清理和留档仍属于 M3。
- GIF 等动图使用原文件临时播放层，保持单份静态缩略图不变。自动播放限文件大小 2 MiB、每个估算解码量 32 MiB、同时最多8张、总估算解码预算128 MiB；估算为宽×高×帧数×4，不代表进程实际内存硬上限。超限或缺帧数信息仅悬停播放；离开可见区、切换页面、应用页面不可见时卸载动图层。识别为动图的 jpg 也适用。
- 鼠标后退/前进改为页面历史：媒体浏览后退回来源页面，前进恢复最后浏览项。方向键切图不增加历史层级。F5仍刷新当前页面/媒体，编辑弹窗阻止侧键意外离开。
- 删除侧栏“浏览”标题，导航自然上移。普通标签编辑不再渲染数值0；父标签区增加搜索，支持中文/英文/拼音首字母，已选项保留并可多选。
- 修正隐藏内容和共用相册/标签浏览器空状态被横向压缩的问题；无内容时占满可用区域居中。保存设置按钮与说明间距增加16px。
- 编辑模式说明将关闭/开启分行；四种视图统一提示空白拖动框选。左右页面边距空白接入同一框选逻辑；继续保持编辑模式反选和自动清空规则。
- 禁止普通界面文字拖选；输入框、媒体详情与任务文件明细保留文字选择。

验证与运行包清单见 workspace 的 `output/audit/m2-directory-settings-20261020/validation.json`。所有窗口验收使用 `tmp/qa` 新建素材和独立 userData；测试启动先校验数据目录和空数据库，每项限时120秒，不访问用户真实图库。

运行包：`release-m2-20261018.4.8.1/win-unpacked/Lumina.exe`。需保留整个运行目录，退出旧版后启动。此次没有 commit/push。

删除与缓存：正常移入软件回收站保留索引和缓存；永久删除/交给系统回收站成功后，以及确认原文件已不存在时，立即清除索引并持久化后台缓存回收。队列定向删除该媒体缩略图及已登记的预览/兼容视频缓存，启动时继续未完成清理，不每删除一项就遍历全部缓存。生成中的预览完成前重新核对媒体指纹，避免删除后再生成残留；数据库关闭时安全停止后台写入。旧版本历史上未登记、且已无法追溯所属媒体的旧预览不做全盘推断删除。

回收站视图：默认列表，支持默认/时间/瀑布/列表四视图、尺寸滑条和完整查询排序，并记忆视图。非列表视图左下角显示剩余天数/已到期/不过期，列表保留还原及彻底删除操作。月份勾选通过全量回收站时间范围查询，包括尚未加载的媒体。

最终验证：14个测试文件144项测试通过，无未处理错误；工程与React严格类型检查、生产构建通过；最终EXE的26项窗口场景通过（目录/任务/标签/回收站15项、GIF4项、导航7项）。细目及截图路径记录在validation.json。
