# M2 .4.2 搜索、相册与全屏视频小修

日期：2026-10-19。分支 feature/M2；独立运行包 release-m2-20261018.4.2。沿用桌面 UI 0.8，本次不升级设计稿、不进入 M3。

## 当前行为

- 主页搜索获得焦点时，默认高亮“标签”。回车确认后继续在标签输入区输入；文件名和标签排除可用鼠标、上下键选择。完成一项或退格返回类型选择时仍以标签为首项。
- 标签、标签排除候选保留原查询和排序，特殊“无”置于首项；空输入也显示现有标签（最多10个），不依赖先打开编辑标签窗口。真实名为“无”的标签显示 #无，与特殊无标签筛选分开。
- 回收站标题下显示总项目和总大小。通过数据库聚合全部回收站记录，超过首屏200项仍统计全部；删除、还原、清空和刷新后更新。不扫描文件系统，隐藏或停用来源不会漏计已有回收站条目。
- 智能相册详情在描述下方显示当前管理标签、同时满足/满足任一关系，以及排除标签；沿用统一双语标签显示。普通相册不显示规则块。
- 缩略图按滑条数值实际改变宽度，包括最大315/320档；Ctrl+滚轮同样生效，保留当前可见媒体位置，最小档仍可进入列表。网格按完整列排列，右侧可能留有不足一列的空间。
- 幻灯片播放期间按 Enter 进入全屏幻灯片并隐藏画面 UI。普通查看及输入框、下拉选择框、可编辑内容中的 Enter 保留原有行为；Esc仍能在视频进度条获得焦点时关闭查看器。
- 全屏视频控件显示时，为视频底部预留工具栏与胶片条的实际高度及8px间隔，原生进度条可见可拖动；换行、16:9、4:3、适应、填充均生效。鼠标位于进度条附近时保持工具栏显示，移回画面中部后收起，视频重新铺满全屏区域。照片幻灯片布局沿用原样。
