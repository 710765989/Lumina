# M2 .4.4 目录标签、目录确认与沉浸浏览

日期：2026-10-19。分支 feature/M2；运行包 release-m2-20261018.4.4；界面基线仍为桌面UI 0.8，不进入M3。

## 使用入口与行为

- 添加目录先打开确认页，显示递归总文件数、照片/视频候选数量、目录数及最多12项内容预览。确认前不登记、不索引；可取消。候选按已知格式统计，真正入库继续校验可读性，不可识别文件不显示。
- 常规 → 图库目录 → 目录设置，可编辑已添加目录。根目录与子目录可各设一个目录标签，留空继承祖先；按目录名填入只填前5层，可继续手动修改。子目录标签属于最近已配置父目录标签，共享现有标签实体；所有标签路径最多5级且不能有环。取消规则只撤销该规则提供的标签，手动标签保留。
- 新增媒体、递归监听、文件重命名/移动后自动应用当前规则；重启仍生效。回收站还原按还原路径匹配。目录标签使用浅青色与文件夹标识，普通标签保留原有样式；悬浮中目录标签优先显示。标签页可改名称/英文/颜色；规则管理的层级与解除须从目录设置操作。
- 自动创建相册：根相册递归包含整个目录媒体。根据原目录层级创建相册：建立可进入的真实子相册，包括空目录；父相册仍包含后代媒体。重复编辑不生成重复相册。关闭自动/层级更新时已有相册和内容保留，新文件只进入仍启用自动更新的相册。
- 配置通过后台任务扫描及整理已有媒体，可查看进度、目录规则、文件名/地址/大小，并暂停、恢复、取消、重试。暂停或取消只停止本次整理，已保存规则仍对新增媒体生效。重叠目录移除其中一个时，保留另一图库覆盖的媒体及手动标签。
- 主页默认沉浸模式，旧偏好在本补丁首次打开时切换一次，之后记住用户选择。鼠标悬浮或键盘焦点显示文件名和标签，浅灰半透明背景占卡片底部30%，不挤压图片。

- 43项相关真实窗口场景：目录确认/规则/悬浮/相册导航/监听/编辑6项，既有new-flows 8项、双向时间轴7项、目录/色板/相册/标签7项、对比/幻灯片7项、followup 8项。新增验证首次视图迁移与后续选择记忆、规则明细；确认页内容可滚动，底栏固定。

## 数据与交付

数据库schema 8，升级前使用SQLite一致快照；标签、规则、相册层级存放在Lumina数据库，不改原文件。目录标签不写入照片元数据，跨机器完整迁移仍需保留数据库。测试使用临时图库，运行包不含用户数据库、图库、日志或缩略图缓存。

保留整个win-unpacked目录，运行其中Lumina.exe。源码和运行包同步到用户本地feature/M2工作区，不自动commit/push；旧版保留。[上一轮 .4.3](m2-update-20261019.4.3.md)。
