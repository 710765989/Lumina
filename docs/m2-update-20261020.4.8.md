# M2 .4.8 浏览性能与隐藏内容

日期：2026-10-20。分支 feature/M2，设计基线0.8，数据库schema仍为8。

- 缩略图固定为640×640边界、保持原比例，每个媒体只保留一个指纹版本；所有缩放和视图共用URL。访问时清理该媒体的旧尺寸/旧指纹缩略图，保留原件、大图预览和视频兼容缓存。损坏缓存仍验证并重建，已验证缓存只核对文件大小与修改时间；指纹URL允许Chromium缓存。清理不会一次遍历并解码整个图库。
- 缩略图请求最多并行3项，按当前可见项目排队，逐项提交显示，移除已离开视窗的未开始请求。卡片按媒体ID保持同一个DOM节点，行列变化不再整行卸载重挂；切换视图、缩放时使用180ms位置/尺寸动画，保持浏览锚点，连续缩放从当前显示位置接续。普通滚动不再逐帧测量所有卡片，原生滚动连续、虚拟窗口分段更新，仍保留预留区域避免空白。
- 常规增加“界面动画”，即时生效并在本机记忆；关闭悬停放大、切换视图、缩放、提示等过渡。系统减少动态效果仍优先停用自动运动；关闭动画不关闭虚拟化和缓存。静态图开启动画时悬停放大8%。媒体卡片间距缩小为2px。
- 新增瀑布视图，顺序为默认视图、时间视图、瀑布视图、列表。按已索引宽高比例排到最短列，限制极端比例高度，保留原图完整信息；仅渲染可见卡片。图库、相册、标签和隐藏内容共用布局及独立视图记忆。
- 时间视图月份标题左侧增加复选框；用相同过滤范围、排序时间及本地月份边界查询媒体ID，选择所有月份项目，包括未加载的记录，不读取原件。再次点击取消该月选择，保留其他月份勾选。适用于图库、相册、标签和隐藏内容。
- 隐藏内容改用共用搜索、类型筛选、排序、视图、缩略图大小、框选和编辑模式；时间轴双向分页、F5和全量查看器播放列表覆盖隐藏范围。底栏常驻加入相册、编辑标签、导出、取消隐藏、删除，移除原“取消单项隐藏”整行。取消隐藏仅撤销手动隐藏；标签规则隐藏要在标签属性取消，不偷偷修改整个标签。主图库标题使用完整有效筛选统计，排除手动隐藏与标签隐藏。
- 标签属性“设为黑名单标签”改为“隐藏标签关联媒体”；移除标签列表和详情的单独隐藏关联媒体按钮。目录标签移除颜色圆点和属性调色区，普通标签颜色保留。
- 重复/相似检测移除“排除首项”，全局和完全重复组内使用“全选／清空勾选”一个按钮。全选包含代表项，整组删除仍需额外确认。相似组使用右侧复选框、半选状态，文件复选框最右侧对齐且无文字，对比按钮位于其左侧。
- 查看器详情侧栏增加独立关闭按钮；右键不再自动收录“保存整理信息”，保存按钮仍留在详情。图库和查看器右键加入“在资源管理器中打开”，详情同一入口统一命名。
- 任务流水线和详情支持取消处理中或等待中的任务，补齐缩略图和兼容视频转换取消。取消保留已完成结果，不自动回退；缩略图安全结束当前项、停止未开始项，兼容转换中止FFmpeg并清理临时文件，避免后续完成回调覆盖取消状态。恢复跳过已完成项目。普通扫描和目录整理保持既有安全停止逻辑。
- 目录监听合并1.5秒内事件，同一目录启动间隔至少5秒；过滤无关文件的change事件、缓存目录和软件回收站。增量预检查指纹，未改变文件不扫描、不新建任务、不发刷新通知；重复的丢失通知不重刷，目录编辑进入整理阶段后恢复不重复扫盘。15秒重连仅维护watch句柄，不定时扫全盘。重复/相似检测仍显式启动，沿用指纹缓存；视图切换、缩放、关闭查看器均不触发文件扫描。
- 发布包清理只处理严格匹配版本名、含完整EXE/asar且无用户数据库、媒体或链接的程序包目录。新包验收后保留最新和上一版；不处理图库、缓存、数据库。清理逻辑包含临时目录回归。

验证：工程和React严格类型检查、生产构建、12个测试文件117项核心测试通过。真实窗口覆盖慢缩略图逐项显示、同节点/同URL复用、动画开关、瀑布布局无重叠、月份全选超200项、隐藏范围搜索/统计/播放、目录标签属性、复选框对齐、取消说明与扫描去重。最终EXE证据和清理清单位于本轮审计目录；机器实测不能替代所有低性能设备的帧率保证。

运行包：`release-m2-20261018.4.8/win-unpacked/Lumina.exe`。保留整个目录；退出旧程序后启动新包，沿用现有数据目录。所有自动验证使用隔离userData和自建素材；未改用户现有图库，不自动commit/push。
