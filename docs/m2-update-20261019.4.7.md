# M2 .4.7 媒体浏览与创建相册交互

日期：2026-10-19。feature/M2；运行包release-m2-20261018.4.7。桌面UI基线0.8，数据库schema仍为8。

## 查看器与缩略图

- 媒体查看器铺满应用客户区，图片按舞台尺寸适应，无页面横向/纵向滚动条。胶片条隐藏滚动条，保留鼠标滚轮和触控板横向滚动。详情长表单保留内部滚动，避免内容不可达；查看器工具栏为Windows窗口按钮预留区域。
- 删除独立“全屏幻灯片”选项及其持久化字段。普通照片、视频与幻灯片均用Enter或全屏按钮双向切换全屏；全屏默认隐藏所有浏览UI，鼠标靠近边缘显示，移回中部后隐藏。视频进度条显示时仍避开工具栏。表单输入/原生select不抢Enter，Escape关闭最上层菜单/弹窗或查看器。
- 顶部移除删除按钮，“信息”改“详情”。媒体右键合并详情、复制、幻灯片、加入相册、编辑标签、隐藏、导出、全屏、切换媒体与删除；图片缩放/旋转及播放操作放子菜单，无“打开”“关闭”和重复项。右键在全屏DOM内显示，删除/标签/导出等外部弹窗操作先退出全屏。只作用于当前打开媒体。删除依旧确认，不直接删原件。
- 胶片条从附近21项改成整个筛选结果的ID播放列表。横向虚拟化，只读取可见窗口及4项余量的记录/缩略图；每次记录请求最多31项，旧响应失效检查。滚动胶片不切换媒体；点击按稳定ID取对应记录，导航时只在必要时显露当前项。图库本身的分页和位置独立。
- 图片可缩小到适应尺寸的10%；适应窗口、100%原图、旋转、鼠标锚定与原件保护保留。
- 文件名/标签浅灰背景alpha由0.86改为0.64。网格间距4px，列表行距2px。悬停图像在卡片内放大4.5%，不改变卡片布局和选中框。视频停留450ms后静音循环预览，离开/失焦/操作/卸载即释放播放器；同一浏览网格只播放当前一段，兼容格式复用既有兼容预览缓存。
- 视图切换和缩略图尺寸变化使用180ms位置/尺寸过渡，继续按媒体ID保留浏览锚点；尊重系统减少动态效果设置。补齐分页结束游标的同步更新与去重，避免快速滚动在React提交之前重复追加同一页。方向键跨未加载边界时，等待正在进行的分页和React提交后再按ID定位；并发向下分页期间向左跨上一页的回归通过。

## 搜索与相册创建

- 主页、相册和标签媒体搜索统一为一级“标签 / 文件名 / 文件格式”，标签二级为“包含 / 排除 / 有 / 无”，移除一级“标签排除”。包含/排除继续输入并匹配中英文标签；有/无直接提交条件，区分真实名为“无”的标签。支持鼠标悬停、上下/左右键、Enter、Backspace，以及外部点击/焦点关闭。
- 相册页只保留“+新建智能相册”。新建页默认勾选“创建智能相册”，展开标签规则、关系与固定五图变更预览；普通相册区在下方折叠。选择“普通相册”后收起智能规则，展开相册标签，并说明“为相册内所有媒体增加标签”。两者互斥；切换时保留尚未提交的各自选项，仅保存当前类型。已有相册类型不转换。
- 排除标签独立折叠，点击标题展开；折叠不撤销已有勾选。普通相册名称、描述保留；为相册绑定标签时增量应用到已加入和之后加入的媒体，并补齐父标签。不因取消相册标签或删除相册而撤销媒体原有标签。
- 排序控件内层hover圆角统一为7px，对齐8px外轮廓；主页、相册和标签浏览一致，保留下拉框外溢显示。

## 文件搜索、导航与界面补齐

- 文件名二级条件为“包含 / 不包含”；沿用子串和拼音首字母匹配。不包含是同一匹配的反向条件，多个文件名条件取交集。
- 文件格式提供常用图片/视频后缀建议，也支持手输后缀后按Enter。忽略大小写，接受jpg、.jpg、*.jpg，统一为.jpg；多个后缀取并集，仅匹配最终后缀。图库、相册、标签的分页、统计、时间轴与查看器播放列表共享后端过滤，不只筛已加载项目。查询使用参数化SQL，无schema迁移；非空前缀/后缀筛选可能扫描候选集合，后台缩略图等任务逻辑不变。
- Windows鼠标侧键前进/返回和Alt+左右键维护最多100条应用内历史，包含相册详情、父子标签、足迹、检测模式和设置页；新导航丢弃前进分支。查看器内侧键切换媒体。保留侧栏原规则：点击当前侧栏回到该页首页，跨侧栏返回保留原页面。
- F5通过主进程快捷键刷新当前数据，不重载React；保持查询和当前集合。查看器中F5重新请求当前媒体；编辑表单打开时不执行导航/刷新，避免丢失未保存内容。图库底栏移除刷新按钮，其余页面原有专用刷新入口保留。
- “全部 / 照片 / 视频”筛选组收窄，窄窗口进一步收窄；标签页的“标签搜索顺序”移到“搜索标签...”右侧，继续记忆选择。
- 相册编辑压缩留白，封面编辑只保留在编辑弹窗内。卡片对齐标题、智能标识和更多按钮，智能卡片显示管理标签。卡片和详情更多菜单统一编辑/删除；详情返回按钮统一为“返回”。
- 重复检测隐藏全局footer；两页主删除按钮统一“删除”。组内/全局“全选”可再次点击取消，“排除首项”默认开启，仅影响全选，手动仍可选代表项。整组全部删除继续二次确认。
- 空回收站不保留撑满页面的列表容器，提示上移；侧栏存储区域上移12px；编辑模式说明明确开启/关闭和编辑成功清空行为；界面“主页”更名“图库”。
- 原生窗口按钮按右上角DOM背景层合成颜色，覆盖普通页面、查看器、弹窗及嵌套弹窗；只改变颜色和图标对比度，保持最小化/最大化/关闭可用。观察DOM变更后合并到下一帧，仅颜色变化才发送IPC。
