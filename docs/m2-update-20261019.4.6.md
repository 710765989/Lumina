# M2 .4.6 统一视图、集合搜索与窗口记忆

日期：2026-10-19。feature/M2；运行包release-m2-20261018.4.6。设计仍为桌面UI 0.8，数据库仍为schema 8。

## 界面与操作

- “沉浸模式”改名“默认视图”，下拉首位；顺序为默认视图、时间视图、列表。主页、相册和标签媒体页一致。网格间距16→8px，月份标题与工具区留白缩小；列表76px行高、4px行距。
- 默认与时间视图共用文件名/标签悬浮样式，浅灰半透明背景；目录标签优先。压缩内边距、字体行高和药丸标签，信息区通常占30%，最小60px，避免小卡片第二行标签被下边缘截断。按用户要求暂不增加标签区滚动。
- 列表加入标签；竖图/宽图按比例完整显示，缩略图与加载/重试占位限制在行内，不裁掉底部。网格保持填充显示。上一个网格模式单独保存，滑动条或Ctrl+滚轮缩小切到列表后，再放大回到原默认/时间视图。
- 标签页标题在最上，提示和搜索框在下方，目录标签与普通标签分组展示。多父引用、层级、编辑、隐藏、删除等继续保留；目录管理的引用仍从目录设置修改。
- 侧栏未选中项hover使用比选中态更浅的蓝色。
- 窗口关闭后记住本次正常大小、位置和最大化状态。全屏幻灯片和临时换屏不覆盖正常大小；显示器断开时恢复到可见工作区；修复高DPI反复重开尺寸增长。

## 相册、标签内搜索及自动隐显

- 相册/标签浏览媒体时加入结构化搜索框，支持文件名、标签、标签排除、无标签/排除无标签、多条件药丸、建议列表、上下键/回车及外部点击/焦点离开关闭。仅在当前普通相册、智能相册或标签后代范围查询。
- 搜索计数、分页、排序和查看器前后切换均对完整集合使用相同数据库条件。空结果显示0项，不显示添加图库；删除条件恢复结果。切换其他侧栏再回来保留当前页，点击当前侧栏返回首页的逻辑保留。
- 智能相册仍有匹配媒体，但全部因隐藏照片、停用目录、隐藏标签等不可见时，卡片自动隐藏；恢复可见后自动出现，实体、规则及封面设置保留。普通相册不受影响。无匹配媒体的新建空智能相册仍可进入编辑规则。
