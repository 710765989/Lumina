## 批量删除确认与保留规则

确认框明确显示“本次删除 N 个文件 · 占用 X”，同时显示保留份数、相册影响与删除目的地，可展开各组保留文件的名称、大小和路径。

“删除相似”默认勾选“保留最大文件”，按文件字节数选择，不按像素数判断。取消勾选时保留该组代表照片。切换选项会重新计算删除数量、大小与保留项，计算期间禁止确认，且保持目的地和详情展开状态。

默认设置下文件移入软件回收站；仍可选择 Windows 回收站或永久删除，永久删除需二次确认。移入软件回收站本身不立即释放磁盘空间。执行前复核计划版本，并重新读取保留原件的状态与 SHA256；原件改变或计划过期会阻止开始删除。耗时核验阶段点击取消不会开始文件操作，开始执行后取消剩余未处理项。

修复 Windows 下查看过的照片被 libvips 内部缓存占用而无法移动的问题：禁用其内部操作缓存，相似特征从文件 Buffer 读取；已有缩略图及预览磁盘缓存继续使用。

## 相似检测实现与数据

自行实现 32×32 图像低频 DCT 哈希、梯度及 4×4 色块特征，结合长宽比筛选；先按 EXIF 方向规范化。使用多段哈希索引缩小候选范围，按代表照片聚组，防止通过中间照片不断串组。完全相同内容由 SHA256 识别。

特征持久化并检查算法版本与媒体指纹；修改文件后失效重算。任务支持暂停、恢复、取消及失败重试；隐藏媒体、停用目录及过期特征不参与结果。数据库升级至 schema 5，新增 similarity_features 表，旧库升级前沿用 SQLite 一致快照。

目前适用于压缩、缩放等视觉接近照片，不是语义识别模型；大幅裁剪、不同视角或复杂编辑可能漏检，相似结果仍需人工比较。算法原理参考 [pHash 设计说明](https://www.phash.org/docs/design.html) 与 [DCT 感知哈希研究](https://www.phash.org/docs/pubs/thesis_zauner.pdf)，没有引入其 GPL 实现或新增依赖；解码与方向处理使用 Sharp。
