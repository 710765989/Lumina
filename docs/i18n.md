# 界面语言 / Interface language / 表示言語

在 **常规 → 界面语言** 中选择简体中文、English 或日本語。立即生效，下次打开恢复；无需网络或翻译模型。文件名、路径、用户创建的标签及相册名称不翻译。标签字段为Tag名／别名；日语界面可离线生成平假名别名。

安装包也可选择这三种语言。中文安装的桌面和开始菜单快捷方式名为「光匣 Lumina」，英语、日语安装为「Lumina」。升级及卸载沿用记录的快捷方式名，切换安装语言时由安装器处理名称变更。首次打开时沿用安装选择；已有用户的界面语言偏好优先。免安装版没有安装语言，初始使用简体中文，可在常规设置切换。

**English:** Open **General → Interface language** and select **English**. Changes apply immediately and are remembered. File names, paths, user tags and album names remain unchanged. All translations are bundled; no online translation or model download is needed.

**日本語:** **一般 → 表示言語** から **日本語** を選択してください。すぐに反映され、次回起動時も保持します。ファイル名、パス、ユーザーが作成したタグ名とアルバム名は変更しません。翻訳は同梱され、ネット接続やモデルのダウンロードは不要です。

## 开发维护

- 渲染层入口：`apps/desktop/renderer/src/i18n.ts`。`t(key, values)` 翻译固定界面文案，`translateMessage` 只用于应用消息。不要把用户名称、路径、媒体信息批量送入翻译函数。
- `locales/catalog.ts`：界面语言表；`locales/backend.ts`：面向用户的业务错误；`locales/extra.ts`：设置及通用错误等补充文案。每条包含英文、日文，缺失时回退中文。
- 数字和用户数据使用 `{0}`、`{1}` 等位置参数，翻译时保留占位符，不对参数做自动翻译。复合操作中的程序动词应先翻译，再作为参数传入；用户标签名保持原文。
- 日期、月份、国家显示使用所选语言；时间轴查询键和后台条件保持稳定。禁止通过翻译后的标签文字反推业务类型。
- `LanguageSettings.tsx` 订阅语言偏好，主应用重新渲染而不重挂载；不调用扫描命令。浏览器偏好保存在 `lumina.ui.language`。原生偏好保存在用户数据目录内 `ui-language.json`，只控制启动与原生对话框。
- `apps/desktop/src/ui-language.ts` 维护原生文案。核心服务、数据库及诊断日志不执行界面翻译；错误在渲染前标准化并翻译。
- NSIS 的 `displayLanguageSelector` 和 `installerLanguages` 明确配置三种语言。`assets/installer-language.nsh` 以LangString为桌面、开始菜单和卸载记录提供一致的快捷方式名，并写安装目录的语言标记；`language-preference.ts` 按用户偏好、安装标记、默认中文的顺序读取。不要由安装器覆盖用户数据库或界面偏好。渲染入口等待本地原生偏好再首次渲染，避免先写回默认中文。
- 添加或修改文案后运行 `scripts/i18n.test.ts`，检查语言表完整性、参数保留、调用点覆盖、任务说明和错误显示。窗口验收覆盖即时切换、重载、搜索、菜单、拖动及长文本布局。

此功能不包含对媒体内容、用户描述、EXIF 地点名或任意日志的机器翻译。新出现且未收录的业务错误会按既有中文文案回退，应在开发时补入语言表。
