# M2 .4.8.10.13 发行说明

## 三种下载

- `Lumina-M2-4.8.10.13-source.zip`：净化源码、资源、文档、演示动图和测试，附逐文件 SHA-256 清单。需要开发环境才能运行。
- `Lumina-M2-4.8.10.13-win-x64.zip`：完整 Windows x64 运行目录，解压后运行 Lumina.exe。
- `Lumina-M2-4.8.10.13-Setup-x64.exe`：NSIS 安装向导，当前用户安装，可选目录，创建桌面和开始菜单快捷方式；默认不在卸载时删除用户数据。

标准软件版本号为 `0.4.8-m2.10.13`，Windows 安装构建号为 `0.4.8.1013`。保留原应用内部名称和 appId，避免升级时切换数据库目录。三种下载的用途不同，GitHub 自动生成的“Source code”也不能代替 Windows 运行包。

## 源码清理与排除

删除了未被当前入口引用的旧 App.tsx、已不用的32像素界面图标、旧 release/release-verify 和隔离测试输出、根目录日志。保留仍在使用的源码、测试、图标源资源、离线城市索引及历史设计记录。开发依赖留在开发环境，但不进入源码 ZIP。

`scripts/export-source.mjs` 使用允许清单导出，拒绝源符号链接和疑似凭据，并排除：

- 用户原始媒体、导入收件箱、软件回收站和用户资料目录。
- SQLite `.db`/`.sqlite`/`.sqlite3` 及 WAL/SHM、媒体索引、浏览器本地存储。
- 缩略图、预览、视频兼容缓存、缓存目录配置。
- node_modules、dist、旧运行包、安装包、临时构建、测试产物、日志。
- Git 元数据、IDE/代理/账号环境配置，以及本机审计与同步清单。

`packages/core/src/data/cities.json` 属于必需的 GeoNames 离线数据，不是用户数据，必须保留。图标 PNG/ICO 和 `docs/images` 下明确列出的两个 GIF 同样是项目资源。演示仅使用生成素材，原始录制帧和测试数据库不发布。发布前按源码清单校验 ZIP，安装器解出内容与免安装 ZIP 逐文件比较。

## 构建与验证

普通开发者从 README 的依赖安装步骤开始，再运行 package:zip 或 package:installer。构建输出不包含已有用户数据，打包临时目录在成功后移除。构建器可能需要下载 Electron/NSIS 工具，不使用硬编码代理。

本次在 `.4.8.10.12` 基础上增加首次添加图库的缓存确认流程，并补充 README 与演示。首次缓存和原缓存位置共15项单元测试、.13 EXE 4项独立窗口验收通过；工程及渲染器严格类型检查通过。原 `.12` 的全量单元与相册/连续动画验收结果作为基线，具体见历史交付记录；不将其误写为本轮重新完成的全量验收。剪贴板实写验收按既有规则跳过，不计作已验证。

完整真实 Windows 安装、卸载和升级的跨机器矩阵仍属后续验收；打包载荷测试不等同于所有 Windows 环境都已覆盖。安装包暂未签名。
