# M2 .4.8.10.3 GIF限制与可见优先级

日期：2026-10-21。沿用设计0.8.1、数据库schema10。本轮仅修改renderer，后端及原生依赖与.4.8.10.2逐字节一致。

常规GIF设置追加大小和数量“不限制”，即时生效且记忆。0是持久化无限制值，缺失设置仍恢复默认2MiB、8个。大小不限制同时解除单项32MiB调度估算门槛；数量不限制同时解除128MiB合计调度预算。两项均不限制时没有人为大小、数量、估算内存拦截，所有可见且可解码的GIF都可自动播放；仍使用逐帧绘制、释放输出帧、离屏和后台停止。

有名额限制时，完整可见GIF优先，其次按实际可视面积由大到小；面积相同时从上到下、从左到右。根据浏览窗口和媒体滚动区域裁剪，底栏遮住的部分不计入可视面积。上下滚动和窗口改变均重新排序，旧项目让出名额。滚动处理由共享requestAnimationFrame合并，只读取已挂载可见动图的位置，每帧共享同一个滚动容器边界，不扫描媒体目录；最后一项卸载后移除监听并取消待执行帧。

验证：242项完整自动测试、React严格类型检查、生产构建通过；最终EXE8项隔离验收通过。24份可见GIF同时播放，包括超过10MB文件及3份2000×2000动图；有限设置恢复、无限制设置持久化、上下滚动名额重分配、离页释放均通过。使用独立测试图库，不触碰真实图库。证据：output/audit/m2-gif-unlimited-priority-20261021/validation.json。

工作区运行包：output/release-m2-20261018.4.8.10.3/win-unpacked/Lumina.exe。保留完整目录。已清理工作区.4.8.10.1，保留.4.8.10.3及.4.8.10.2。本轮尚未同步外部Git项目，不commit/push。
