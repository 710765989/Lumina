# M2 交互、层级标签与后台任务交付

日期：2026-10-18；开发分支 feature/M2；界面基线桌面 UI 0.8，设计文档不升版。本页记录历史运行包 release-m2-20261018.4；最新小修见 [M2 .4.1交付](m2-update-20261019.md)。

## 本轮行为

| 范围 | 当前实现 |
|---|---|
| 编辑模式 | 主页 footer 左下开关；单击追加/取消一项，空白不清选区，框选保留原选区。关闭恢复 Windows 单选及 Ctrl/Shift 多选。按钮下有简短提示，问号可悬停/聚焦查看完整说明。 |
| 操作与选区 | 加入相册、编辑标签、导出、隐藏、删除及刷新后清空勾选；取消弹窗保留选择。后台任务提交后消费本次选区，完成通知不覆盖后来新选区。 |
| 编辑标签 | 添加/移除合并；× 只允许移除共同标签。空输入显示最近使用10个标签；候选默认首项、支持键盘和鼠标自动提交，提交后下拉关闭。连续添加默认不勾并记忆，固定本次媒体目标，因此主页清空后仍可继续编辑同一批媒体。 |
| 层级标签 | 最多5级，添加子标签自动关联祖先；树形列表可折叠，父级列出后代及其媒体。拖动可成为其他标签的子级，顶部区域可拖回根；循环/超深移动原子拒绝。拖动区域预留高度，避免目标位移。 |
| 删除父标签 | 提供保留并上移子标签/连后代删除两种选择，保留原文件并提示智能相册影响。父标签浏览、搜索和智能相册匹配包含所有后代；隐藏父标签也覆盖后代，解除后恢复原手动封面。 |
| 搜索与数量 | 搜索只在主页数量下方；拼音首字母/全拼匹配文件名和标签。主页总数按完整搜索、媒体类型与隐藏排除后的结果统计，与已加载页数无关；侧栏存储仍显示全图库有效数量。 |
| 下拉关闭 | 搜索方式/建议、排序、标签候选、相册更多及媒体右键菜单统一点击外部关闭；Tab或程序焦点转到其他控件、窗口失焦同样关闭。触发区与浮层属于同一区域，在内部选择不会提前关闭。原生 select 保持 Windows 行为。 |
| 主页视图 | 时间视图/沉浸模式/虚拟列表，缩略图滑条与Ctrl+滚轮；最小时继续缩小转列表。沉浸隐藏月份和文件名，让图片占满；视频中央播放标记，移除类型角标。加载提示仅慢加载时显示，消息在footer上方。 |
| 页面导航 | 切换大页面保留原层级/位置；再次点击当前菜单回首页。Backspace返回上一层，输入框中不拦截。0项页面不反复刷新。 |
| 查看器 | 点击窗口外关闭；视频控件聚焦时Esc也有效。幻灯片保留设置和音乐选择，勾全屏后隐藏UI，鼠标到边缘显示。按实际格式识别动画，GIF改为jpg后仍使用原始内容播放。 |
| 重复与相似 | 两页分别直接打开“删除重复”/“删除相似”确认；相似支持复选删除项，移除“完全一致”文字但保留一致副本优先。确认显示文件数、字节数、保留项和目的地；保留最大文件可切换。 |
| 后台批处理 | 删除、还原、清回收站、批量隐藏及既有标签/导出/检测持久化，可关闭进度窗后台运行，在顶部任务入口或常规任务状态查看。显示已处理数、百分比、完成字节、当前阶段/路径，支持暂停/取消、继续未执行项和仅重试失败项。任务状态后端分页，每页10条。 |
| 取消与文件安全 | SHA读取可中断；停止后不再派发下一项。当前系统复制/回收调用需要安全完成，不能保证所有格式都瞬停。删除前按组核验保留原件，排队期间变化会拒绝。Windows短暂占用最多有限重试，等待可中断、重试前重新核对内容，失败保留原件。 |
| 目录扫描 | 目录监听合并变化路径，增量扫描并复用后台扫描任务；并发手动扫描合并，避免每次变化都全库扫描或堆积历史任务。 |
