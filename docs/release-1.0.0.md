# Lumina 1.0.0

1.0.0基于本地已验收的.4.8.10.25代码发布，应用版本、安装器版本和下载文件统一使用1.0.0，Release不再标记Pre-release。数据库仍为schema12，保留既有数据目录、缓存配置和安装标识。版本号调整不代表把历史待验项目改记为通过。

README改为使用者入门说明：先讲现有文件夹集中浏览、一份原件多种分类、智能相册规则、对比清理和拖出素材，再说明下载、第一次使用、数据保存和边界。新增README.en.md与README.ja.md，三份互相链接，保留两段独立示例图库交互动图。

本版包括此前本地补丁中的足迹封面、标签拖动与Ctrl复制、多语言界面、离线日语读音与罗马音检索，以及安装器语言对应的快捷方式名。中文快捷方式为「光匣 Lumina」，英语、日语为「Lumina」。

发布文件为安装包、免安装ZIP、净化源码ZIP及SHA256SUMS.txt。源码导出采用允许清单，排除真实媒体、数据库、缓存、日志和凭据；发行版保留第三方许可。项目级源码许可证仍由项目所有者决定，本次不新增许可证或改变仓库可见性。

继续保留的范围说明：隐藏不是加密；相似检测辅助人工选择；特殊编码不保证可解码；跨机器、跨应用及10万真实媒体的长时间测试见m2-acceptance.md，不以本机隔离测试替代。账号与加密、局域网分享、高级媒体处理等仍按后续规划开发。

升级前关闭软件，备份原件及用户数据目录。仅替换或升级程序，不删除原图库、整理数据库或现用缓存。
