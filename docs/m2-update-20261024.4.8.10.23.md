# M2 .4.8.10.23：标签拖动光标与中英日界面

标签拖动柄悬停错误显示“加载中”的原因，是旧的 `[draggable=false]` 样式覆盖了新的自定义拖动手势。已移除该判断：普通标签悬停为抓取手势、按下及拖动为抓取中、Ctrl 拖动为复制。目录标签及保存中的标签使用明确的禁用属性，不再把原生拖动开关当成加载状态。

常规设置顶部新增「界面语言」，提供简体中文、English、日本語。切换立即更新界面并保存选择；浏览器界面及原生启动窗口、文件选择器记住语言。未设置时保留简体中文。不联网、不下载翻译模型。

安装包启动时显示语言选择窗口，提供 English、日本語、中文（简体）。安装向导使用所选语言，并在安装目录写入 `installation-language.json`，供无既有偏好的首次启动使用；已有用户保存的语言选择优先，不被升级覆盖。

界面文案、菜单、弹窗、任务说明、空状态、悬浮提示及常见业务错误使用本地语言表；日期、月份、国家名称按所选语言格式化。原始文件名、路径、输入内容、用户标签和相册名称保持原文，不自动翻译；标签已有的中英文名称字段不改变。

翻译在显示层执行。后台命令、任务类型、搜索条件、月份分组键、目录规则、数据库记录和文件操作错误标识不变。切换语言不重启服务、不触发目录重新扫描、不修改图库。数据库仍为 schema12。

实现与维护说明见 [多语言维护](i18n.md)。此版本为本地测试包；未上传新的 GitHub Release。

验证结果与最终可执行文件的窗口证据记录在工作区 `output/audit/m2-i18n-20261024/validation.json`。发布前应继续进行其他机器和不同系统缩放比例的人工排版验收。
