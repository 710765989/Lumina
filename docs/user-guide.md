# 1.0.1 正式版说明

当前应用版本为1.0.1，数据库schema12。可从已有0.4.8系列升级，升级前关闭软件并备份原件与用户数据。安装器中英文／日文快捷方式为Lumina，中文为光匣 Lumina。入门介绍见README及英语／日语版README；下面保留详细用法和历史功能说明。

# 使用、升级与数据保护

## 界面语言

安装程序启动时可以选择简体中文、English 或日本語，首次运行沿用安装选择；已有用户的语言偏好保留。在「常规 → 界面语言」选择简体中文、English 或日本語，立即生效并保存。下次启动使用上次选择，启动小窗和原生文件选择器也跟随语言。文件名、路径、用户标签和相册名称保持原文。翻译随软件提供，不联网、不下载模型。切换语言不会重新扫描图库。

English: General → Interface language. 日本語：一般 → 表示言語。[详细说明 / Details / 詳細](i18n.md)。

## 添加目录和导入的区别

首次添加图库时，在目录确认页同时确认缓存目录，显示剩余空间并验证可写后才开始扫描。取消页面不会保存缓存选择或启动扫描；已有图库沿用实际路径，后续更改通过缓存迁移完成。

添加图库目录建立原文件的索引，不复制原件。停用目录会从可见图库隐藏其媒体；启用后恢复显示。移除目录移除相应索引，不代表删除原文件。

导入会把所选文件复制到确认的目标目录，支持拖入、粘贴和批量文件夹。未勾选“不再提示”时仍弹出路径确认，并带上上次选择的目录。同名文件需要确认处理方式，不能把目录自身再次导入自身。

## 相册、标签与隐藏

普通相册保存媒体引用；智能相册根据包含/排除标签规则自动筛选。智能相册中排除的媒体可通过“管理排除项”找回。相册文件夹仅组织相册层级，不创建同名磁盘目录。

目录标签对目录与子目录递归生效，普通标签可独立编辑。当前隐藏可以来自手动隐藏、隐藏标签或停用目录。手动取消隐藏不会自动解除其他隐藏来源；界面可显示原因，并对隐藏标签选择“仅显示此项”等处理。目录停用不受单张例外影响。

同步 Windows 隐藏属性是可选功能；启用后可能修改原文件的 Hidden 属性，并记录原状态用于恢复。隐藏不是加密。Vault 加密属于 M3 规划。

## 足迹与地点分类

`.4.8.10.14` 起，扫描照片时读取 GPS 并离线匹配附近城市，足迹页直接读取已保存地点，无需再扫盘。旧图库点击“补充地点分类”时优先使用已有元数据；仅缺少元数据的旧记录需要补读一次原文件。已确认无 GPS 的照片跳过，已整理且未变化的照片也跳过；按钮不会替你重新扫描目录。

`.4.8.10.16` 起，地点仅在足迹展示，不创建地点标签或地点相册，也不显示这两项创建选项。“更新足迹”只更新已保存的地理元数据，复用 GPS 并跳过无变化项目，不复制文件。

足迹封面在进入可见范围后加载，最多四张照片拼贴；候选图片不可用或当前 HEIF 编码不支持时跳过并尝试其他候选，全部不可用时显示占位和手动重试，不循环自动请求。进入地点后可搜索当前范围、切换默认/时间/瀑布/列表视图、使用滑条或Ctrl滚轮缩放，动画遵循常规设置。完成后不显示撤销入口。

`.4.8.10.17` 起封面只渲染可显示的照片，按数量填满区域：1张铺满、2张左右平分、3张一大两小、4张四宫格。例如地点有3项，但其中HEIC不可解码时，以两张正常照片平分封面，不保留另外两个空格；地点项目总数仍为3，不因封面候选失败而删减。

如旧版曾自动创建地点标签/相册，足迹页显示“清理旧地点分类”。确认页显示自动相册与关联数量；确认后仅按自动来源标记移除分类，不按名称前缀删除。原媒体与足迹元数据保留，普通相册、同名前缀的手动标签不受影响；已被手动使用或其他规则引用的旧地点标签保留为普通标签。取消不修改数据，分类变化后必须重新确认。

离线结果为附近城市，不代表精确行政区或实时地图定位；没有 GPS 就不会凭画面猜测地点。视频目前不参与该照片地点分类任务。

## 删除与任务

软件回收站与 Windows 回收站不同。删除时按界面选择目的地，软件回收站中可查看剩余天数并恢复；永久删除无法通过本程序撤销。重复或相似检测只辅助筛选，删除前检查保留项，尤其不要把视觉相似等同于内容完全一致。

后台任务按实际类型支持暂停、继续或取消。取消通常停止尚未执行的部分，已完成的文件操作不会一概自动回滚。请查看任务状态与文件明细，而不是把取消等同于恢复整个批次。

## 数据与升级

1. 在“常规 → 缓存设置”记录数据库和缓存的准确路径。
2. 升级前关闭 Lumina，备份用户数据目录和原媒体。数据库的标签/相册关系不能只依靠原照片恢复。
3. ZIP 版解压到新目录再运行，不要只复制 `Lumina.exe`。安装版按安装向导更新。
4. 旧版保留实际数据库及缓存配置；新装缓存默认程序旁 `cache/media`。移动缓存请使用软件内迁移功能。
5. 卸载默认保留用户数据库，目前没有独立缓存删除选项；安装目录内缓存随程序目录删除，外部缓存保留。删除缓存通常只影响首次重新生成速度；删除 SQLite 数据库会丢失整理关系。

数据库升级前有自动备份，仍建议保留独立备份。升级数据库后不要直接让旧程序修改新数据库；回退需同时恢复兼容的数据备份。

## 反馈问题

提供版本号、Windows 版本、操作步骤及任务中的中文错误信息。日志和截图可能含私人路径、文件名或坐标，请先脱敏。不要将真实数据库、缓存、图库或账号配置提交到 GitHub。

`.4.8.10.18` 起，“更新足迹”的提示说明会检查并更新地点信息、优先使用已保存的 GPS、不重新扫描整个图库。封面按拍摄时间倒序，缺失时使用文件修改时间，同时间按内部标识稳定排列。首批12张仅作为起点，遇到不可解码照片继续分页寻找后面的候选，直到4张可用或该地点没有其他照片。返回页面不重复尝试失败候选；缓存保留最多64个闲置地点，媒体内容或位置变化后更新。封面加载中途离开可见范围时停止继续寻找，重新可见后继续。

`.4.8.10.19` 修正封面与地点内排序不一致：默认都按文件修改时间倒序；地点内改变排序后，返回时封面跟随同一排序与方向，跳过隐藏及无法显示的候选，取前4张可用照片。拍摄时间模式没有拍摄时间时继续用修改时间。封面悬停说明当前规则。隐藏靠后的照片不改变前面正常封面；隐藏封面项则取下一张可用照片补位。这里仅改变足迹地点封面，不改变普通相册的手动封面。

`.4.8.10.20` 起标签合并说明统一放在合并确认窗口，标签首页不再重复显示；标签拖动提示位于固定底栏，该底栏仍可接收拖入以解除当前父标签引用。回收站的已选数量、还原所选、还原到其他目录和彻底删除位于固定底栏，不再显示静态“已加载xx项”。足迹统计卡片降低高度并收紧下方留白。

`.4.8.10.21` 起目录标签和普通标签分别选择父标签，父标签搜索、创建时已有标签名称建议及合并目标只列出同类型标签；两种类型不能建立父子关系或合并。目录规则管理的层级仍须到目录设置修改。同类型普通标签仍可多父引用和合并。属性中的“分组”暂无实际展示/筛选功能，因此隐藏输入，保留历史值，保存其他属性不会清空历史分组。

`.4.8.10.22` 标签拖动：从标签行左侧拖动柄拖起，整行预览跟随鼠标，目标父标签下先出现占位，其他标签平滑让开；松手后立刻在新位置显示并后台保存。普通拖动仅移动当前父引用，其他父引用保持。按住Ctrl拖动则复制引用，原父引用保留；从顶级拖出也保留顶级入口。Ctrl可在拖动过程中按下或松开；复制到已有位置不重复添加。普通拖到底栏可移到顶级，Ctrl拖到底栏可增加顶级入口。额外顶级入口可用“删除引用”解除，标签本身及其他引用保留。

拖动到折叠父标签时会临时展开目标路径，取消后恢复；靠近列表上下边缘可滚动。Esc、失去焦点或离开页面会取消未提交拖动。保存失败恢复原层级，保存成功后布局不回跳。动画遵循常规设置；关闭后仍显示跟随与占位，只取消平滑让位过渡。目录规则标签的层级仍由目录设置管理，不能跨普通/目录类型或形成循环，最多5级。

为保留“顶级＋父标签下”两种引用，数据库升级为schema12，在标签记录增加顶级引用标记，不复制标签记录或原媒体。首次打开旧库前自动创建一致备份；升级后不建议再使用旧版程序编辑标签层级。

## Tag 名、别名与日语搜索

标签编辑中填写 Tag 名和可选别名，现有英文名作为别名继续保留。中文界面支持拼音，英语界面按原名和别名匹配，日语界面支持假名及罗马音，例如 shashin 可找到写真。日语输入汉字或片假名时，会自动填入平假名别名；可手动修改，已有别名不覆盖。

日语词典已随安装包提供，约17 MB，不需要联网或重新扫描图库。首次使用需要短暂准备，闲置后自动释放解析器内存；罕见姓名、多音词可能需要手动校正。

## 删除相册及下级

删除父相册或相册文件夹时，会同时删除其全部下级相册。确认窗口列出范围与总数；仅删除相册及其关系，原媒体和标签保留。独立创建、只是使用相同目录或媒体的相册不受影响。确认期间层级改变时，需要刷新删除范围后重新确认。
