# 使用、升级与数据保护

## 添加目录和导入的区别

首次添加图库时，在目录确认页同时确认缓存目录，显示剩余空间并验证可写后才开始扫描。取消页面不会保存缓存选择或启动扫描；已有图库沿用实际路径，后续更改通过缓存迁移完成。

添加图库目录建立原文件的索引，不复制原件。停用目录会从可见图库隐藏其媒体；启用后恢复显示。移除目录移除相应索引，不代表删除原文件。

导入会把所选文件复制到确认的目标目录，支持拖入、粘贴和批量文件夹。未勾选“不再提示”时仍弹出路径确认，并带上上次选择的目录。同名文件需要确认处理方式，不能把目录自身再次导入自身。

## 相册、标签与隐藏

普通相册保存媒体引用；智能相册根据包含/排除标签规则自动筛选。智能相册中排除的媒体可通过“管理排除项”找回。相册文件夹仅组织相册层级，不创建同名磁盘目录。

目录标签对目录与子目录递归生效，普通标签可独立编辑。当前隐藏可以来自手动隐藏、隐藏标签或停用目录。手动取消隐藏不会自动解除其他隐藏来源；界面可显示原因，并对隐藏标签选择“仅显示此项”等处理。目录停用不受单张例外影响。

同步 Windows 隐藏属性是可选功能；启用后可能修改原文件的 Hidden 属性，并记录原状态用于恢复。隐藏不是加密。Vault 加密属于 M3 规划。

## 删除与任务

软件回收站与 Windows 回收站不同。删除时按界面选择目的地，软件回收站中可查看剩余天数并恢复；永久删除无法通过本程序撤销。重复或相似检测只辅助筛选，删除前检查保留项，尤其不要把视觉相似等同于内容完全一致。

后台任务按实际类型支持暂停、继续或取消。取消通常停止尚未执行的部分，已完成的文件操作不会一概自动回滚。请查看任务状态与文件明细，而不是把取消等同于恢复整个批次。

## 数据与升级

1. 在“常规 → 缓存设置”记录数据库和缓存的准确路径。
2. 升级前关闭 Lumina，备份用户数据目录和原媒体。数据库的标签/相册关系不能只依靠原照片恢复。
3. ZIP 版解压到新目录再运行，不要只复制 `Lumina.exe`。安装版按安装向导更新。
4. 旧版保留实际数据库及缓存配置；新装缓存默认程序旁 `cache/media`。移动缓存请使用软件内迁移功能。
5. 卸载默认保留用户数据库，目前没有独立缓存删除选项；安装目录内缓存随程序目录删除，外部缓存保留。删除缓存通常只影响首次重新生成速度；删除 SQLite 数据库会丢失整理关系。

数据库升级前有自动备份，仍建议保留独立备份。升级数据库后不要直接让旧程序修改新数据库；回退需同时恢复兼容的数据备份。
