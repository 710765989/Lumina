数据库当前 schema 8，升级前保存 SQLite 一致快照，相似特征持久化并按媒体指纹失效；整理信息与缩略图缓存分开。目录停用后隐藏媒体，移除清理相应索引；软件回收站文件与记录独立保留。同步 Windows 隐藏属性默认关闭，恢复时使用原 Hidden 位。

最新独立目录包：release-m2-20261018.4.8.7/win-unpacked/Lumina.exe。运行时需要保留同目录依赖；包中不包含用户数据库、图库或缓存。完整相册/标签关系只保存在原文件之外的 Lumina 数据库，迁移时需要一并保留。
