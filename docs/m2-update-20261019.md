# M2 .4.1 标签、浏览定位与检测对比修正

日期：2026-10-19。开发分支 feature/M2；代码小版本 release-m2-20261018.4.1，沿用 .4 的命名并追加 .1。界面基线仍为桌面 UI 0.8，本次不升级设计文档、不进入 M3。

## 本轮变化

| 范围 | 当前行为 |
|---|---|
| 唯一标签与多父引用 | 每个标签只有一个 ID 与名称记录，tag_edges 单独保存父子引用。同一标签可被多个父标签引用，也可以拥有子标签；最多5级，拒绝循环和任一路径超过5级。媒体、搜索、隐藏与智能相册沿所有祖先关系匹配，重复路径不会重复计算媒体。 |
| 标签移动与删除 | 拖动立即显示预期结果，只移动当前父子引用，其他引用保留；失败回退。删除弹窗区分删除引用与删除整个标签。删除最后一个父引用后标签成为顶级标签。全局删除前说明关联媒体和智能相册影响；可选删除本分支独有子标签，仍被其他分支引用的共享后代保留。原媒体不会因删除标签而删除。 |
| 中英文名称 | 分别保存标签名称与英文名；本轮按用户决定手动填写英文。纯英文输入会自动复制到英文名字段，仍可编辑；显示为中文（English），两者一致时仅显示一次。标签页、建议、相册规则与媒体详情使用统一显示；支持中文、拼音首字母/全拼与英文搜索。没有接入模型、在线翻译或额外下载。 |
| 标签子菜单与排序 | 编辑标签的候选列表悬停/聚焦标签显示右侧子菜单，列出直属子标签并可新增子标签。支持方向键进入/返回、点击子标签直接添加；新增窗口保留父标签和原编辑目标。标签页可设置搜索顺序，默认最近选择，可改按名称，子标签紧随父标签；配置持久化。共享标签在建议列表中仍只出现一次。 |
| 标签性能与后台提示 | 单图任务只核对本次目标，不读取全库元数据；移动标签只重算受影响媒体。慢任务可后台运行，右下显示进度与成功/失败结果并避让主页 footer。快速操作不丢任务历史。 |
| 任务摘要与明细 | 一批标签/缩略图工作合并成一条任务记录，动作写明标签编辑·新增/移除以及完整标签路径。详情按20项分页保留当时文件名、路径、大小、状态和错误，列表按10条分页；缩略图有详情及仅失败项重试。标签进度去掉完成 MB，仅显示数量、百分比和结果；文件大小只保留在逐文件明细。 |
| 无标签搜索 | 标签与标签排除的候选末尾都有特殊选项“无”，用于只看无标签或排除无标签媒体；与真实名称为“无”的标签区分。筛选数量、分页、播放列表一致。 |
| 整库时间轴 | 右侧月份聚合覆盖当前完整筛选结果，支持直接跳到尚未加载的月份，按日期区间索引分页读取；不先加载之前所有媒体。拖动释放后合并请求。文件时间/拍摄时间排序提供时间轴，文件名/大小排序隐藏。主页统计保持完整筛选数量，月份标题显示整月数量。 |
| 方向键与浏览位置 | 方向键移动选择，Shift范围、Ctrl只移焦点、Ctrl+Shift上/下覆盖当前筛选全部前/后项（包括未加载项）；移动后自动滚到焦点媒体。输入控件/弹窗不拦截。缩略图滑条、Ctrl滚轮和列表转换保留当前可见媒体锚点，避免跳回前面。 |
| 编辑模式与目录开关 | 编辑模式和常规目录启用均改为蓝白 ON/OFF 滑动开关。编辑模式中单击、框选、Shift范围对原选择反选，框选/连续键盘范围以手势开始时的选区为基准，避免每帧反复翻转。浏览模式提示包含框选多选。目录状态仍显示启用中/停用中。 |
| 智能相册排除找回 | 详情页“管理排除项”支持20项分页，恢复单项、选中或全部。恢复仅解除本相册排除，隐藏、停用、回收站与标签规则仍有效。 |
| 重复与相似检测 | 两页初始均不勾选删除项，可一键勾选本组或各组非代表项；删除只处理明确勾选的项目，至少保留一份，确认列出文件数与空间。对比按钮左侧显示代表照片、右侧显示当前照片，两侧等宽并保持比例；视频重复也可打开播放器对比。完全重复删除预览绑定具体删除集合，确认或排队期间结果变化则拒绝。 |
| 文案与提示 | 可预期的错误只显示原因，例如标签名称已存在，不带 Electron IPC 包装。软件回收站选项改为“软件回收站·可恢复”。非幻灯片时隐藏全屏幻灯片复选框。 |

## 验证

- 工程与 React 渲染器类型检查、生产构建通过；85/85项核心测试通过（9个文件）。
- 七组共32项真实窗口场景通过：responsive-tags 4、new-flows 8、selection-switches 4、editing 6、task-information 3、dropdowns 4、tag-submenu 3。窗口均使用自建媒体和隔离数据库。
- 最终 .4.1 EXE 实际启动并通过16项冒烟检查，验证原生SQLite、FFmpeg、缩略图/预览、检测、后台删除还原、共享双语标签、时间轴和对比。包内不含用户数据库、图库或缩略图缓存。
- 4万条合成媒体、8万标签关联的SQLite基准：单图标签任务约18.76ms；最近标签约0.53ms；移动关联10张媒体的标签约130.15ms。旧基准对应约586.12ms、64.72ms、1113.66ms。这是合成数据库测量，不包括真实媒体扫描和解码，也不是跨机器性能承诺。
- 任务信息与文件快照在重启后保留；单父标签旧库迁移、多父继承去重、共享后代保护、循环/深度校验、双语搜索和精确删除集合均有核心测试。

## 数据与边界

数据库 schema 7：旧单父关系迁移到独立引用表，增加 english_name，升级前保存SQLite一致快照。旧版程序不能反向打开已升级库。标签与相册关系仍只存在Lumina数据库中；媒体原文件不因改名、移引用或删标签而改写。

继续保留此前跨应用复制/拖出、跨机器和真实10万媒体压力等人工待验边界。当前没有自动历史清理或留档：相关需求明确记录在 [M3任务履历计划](m3-task-history.md)，M3开发前必读。

本轮未 commit、push 或合并分支；已有未提交代码保留。
