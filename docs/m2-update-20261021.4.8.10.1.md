# M2 .4.8.10.1 GIF 设置与相册首页搜索

日期：2026-10-21。沿用设计0.8.1、数据库schema10；不变更图库、数据库和缓存位置。

- GIF 自动播放资格随大小设置直接重新计算，已显示缩略图不必重建可见性观察器；数量设置也即时生效。保留512KB–10MB、1–16个选项、默认2MB/8个、单项32MiB及合计128MiB估算解码预算。文件体积符合限制并不代表解码内存符合限制，超出预算仍只悬停播放。
- 统一虚拟网格、旧分组网格、相册封面、排除项预览的动图元数据传递；相册/标签的现用主网格原本已经传递动图参数，本补丁不将遗漏的旧网格误认为所有页面均失效的唯一根因。
- WebM 保持视频分类，现有悬停预览静音循环播放、移开后释放；未加入GIF自动播放范围。
- 相册首页搜索仅按相册名称或描述返回相册卡片，不按文件名或媒体标签返回媒体。增加相册记录类型边界、搜索标签、明确的空结果反馈。首页搜索可找到下级相册；打开后子相册列表只显示直接下级，不再受到首页残留关键词影响。进入相册后的媒体搜索仍单独保留。
- 未在隔离库复现旧版首页直接返回媒体记录：旧版列表本身映射的是相册数组。可复现的问题是首页关键词影响已打开相册的子相册列表。补丁增加混合输入防护及窗口测试，不将未复现的现象标为已定位的同一根因。

验证：230项自动测试通过；React严格类型检查、生产构建通过；最终EXE通过8项既有GIF检查及5项新增GIF即时设置、WebM、相册搜索检查。仅使用隔离素材和数据库。证据：`output/audit/m2-gif-album-search-20261021/validation.json`。

此补丁只替换经过构建的renderer；与.4.8.10对比，打包内其他后端、原生依赖、运行时文件逐字节一致。运行：`release-m2-20261018.4.8.10.1/win-unpacked/Lumina.exe`，保留整个目录。发布包保留本版及.4.8.10，不commit/push。
