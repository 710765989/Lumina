# M2 .4.5 AVI播放与任务筛选

日期：2026-10-19；feature/M2。运行包 release-m2-20261018.4.5，数据库仍为schema 8，无新增数据库升级。

- AVI普通查看直接选择已有兼容播放链路，首次需要准备H.264/AAC缓存，之后复用。无需先遇到错误再点“生成兼容预览”。原生支持的MP4等格式继续直接播放；遇到解码错误或不支持编码时自动回退一次。兼容失败显示原有重试/任务入口，不无限循环。文件名大小写均识别；切换媒体时不将上一个媒体的兼容状态带入下一个。兼容播放器加载后重新应用当前倍速，拖动、方向键、全屏和Esc沿用原交互。原文件保持只读，缓存仍由媒体ID与指纹绑定，源文件变化后失效。
- 任务列表默认全部，待处理（处理中/等待中/已暂停）排在其他历史之前，各组内部仍按创建时间从新到旧。已取消记录保留在全部中。`tasks.list`和`tasks.page`共用排序。
- 常规 → 任务状态增加状态筛选：全部（待处理优先）、待处理、已完成、失败。数据库先筛选完整历史、再计数与分页，每页仍5条；更换筛选回第一页，结果变少时修正页码，空结果显示文字。已完成/失败不影响任务本身。现有“全部重试”仍针对全部失败或暂停任务。
