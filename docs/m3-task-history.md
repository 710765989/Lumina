## 当前版本先完成的部分

任务列表与详情写清实际动作：添加/移除哪个标签及当时完整层级路径；删除目的地、隐藏/恢复、导出目的地等。批处理逐文件保留文件名、完整源路径、字节大小、执行结果及失败原因，导出另有输出位置。信息在任务执行前冻结；媒体后来改名、移出或删除后，历史记录不依赖当前媒体行补查。任务显示创建和更新时间、成功/失败/未执行数量、处理进度，可分页查看已存历史。

## M3 待实现需求

| 需求 | 开发要求 |
|---|---|
| 7天前历史自动清理 | 对超过7天的已结束任务提供自动清理；运行/排队/暂停中或仍需恢复的任务不作为历史直接删除。明确使用完成时间计算保留期，不能仅按创建时间清掉长任务。当前版本不启用任何自动清理。 |
| 是否留档 | 设置中提供留档选项。启用时必须先成功输出并校验档案，再清理库内历史；输出失败保留数据库记录并提示。关闭留档后的清理含义需在设置中明确。 |
| 最近一次/多次留档 | 可只保存最近一次，也可保留多次履历；多次的保留数量可配置。仅保存最近一次时，在新档案写入成功之后再处理旧档案，不提前删掉唯一副本。 |
| 输出目录 | 支持用户选择和修改任务履历输出目录；检查目录不可用/无权限/空间不足并记录结果，不能影响原媒体文件。 |
| 自定义输出名 | 支持例如“xxx-年月日”，提供年月日占位符与实际文件名预览；处理不合法字符和同日重名，使用时间或序号后缀避免误覆盖。 |
| 查看之前的历史 | 提供任务履历入口，能区分当前数据库历史与已留档历史，按时间、任务动作、状态搜索/筛选，查看摘要和逐文件明细并分页。 |
| 读取任意一次履历 | 可选择任意一次档案读取，即使不在当前输出目录也可打开。校验版本与完整性，导入历史默认只读查看，不自动重新执行档案中的任务/文件操作。 |

## 数据与验收约束

- 档案需有格式版本、生成时间、任务ID/动作/参数、创建/完成时间、预筛与目标数量、成功失败结果，以及逐文件名称/历史绝对路径/字节大小/结果/输出位置；标签保存当时的名称和层级路径。批处理内源文件应有稳定ID与指纹，原有记录有缺项必须显式标识。
- 使用适合大任务的可流式明细格式（例如清单+JSONL），写临时档案、校验后再提交最终文件；不要求把十万条明细一次载入内存。存量任务迁移不能伪造当时不存在的快照字段。
- 验收覆盖7天边界、长任务保护、留档开关、最近一次/多次、输出失败、重名、读取其他目录任意档案、旧格式、损坏或缺失档案，以及媒体已经删除/移动后的历史查看。
- 所有自动清理只影响任务历史/履历档案，不能删除图库、媒体原件、相册、标签或缩略图缓存。M1尚未完成的完整数据备份迁移仍单独记账，不以本功能替代。
