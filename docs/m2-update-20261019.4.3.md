# M2 .4.3 时间轴、批量整理和媒体浏览修正

日期：2026-10-19。分支 feature/M2；代码小修包 release-m2-20261018.4.3，界面仍沿用桌面 UI 0.8。数据库 schema 仍为7，本轮不进入M3。

## 时间轴与浏览

- 月份定位改为完整查询中的分页位置，不再将所选月份当成时间范围筛选。初次只取目标位置200项，向上滚动按需补前页，向下继续取后页；补前页时保持可见媒体锚点。键盘可跨越上方未加载边界。再次点击同月回到月初；快速切换忽略过期结果。正倒序和标签筛选均保持完整数量及范围。
- 相册和标签详情共用媒体浏览组件，加入缩略图大小、Ctrl+滚轮缩放、时间/沉浸/列表视图、四种排序及正倒序。排序在数据库中对整个集合执行，分页与预览播放列表使用同一顺序；拍摄时间缺失时按文件修改时间回退。配置分别保存在本机。
- 相册/标签列表采用与主页相同的虚拟时间网格和慢加载提示，不再常驻“继续下滑自动加载”或末尾统计条。提示在底部实际等待加载时才可见。
- 相册详情底栏常驻显示，未选择时禁用操作；普通相册的“从此相册移出”、智能相册的“加入排除项”从内容上方移到底栏。成功后清空选择，原媒体保留。标签/相册的选择、右键和媒体预览继续沿用现有操作。

## 重复与相似整理

- 本组及各组“勾选非代表项”可再次点击取消，按钮文字同步变化；这些快捷操作会取消代表项勾选，代表项仍可手动选择删除。
- 对比窗口左右两侧均增加“删除此项”，与列表中的勾选实时共享。上一张/下一张按钮及键盘左右键切换组内其他文件，代表项留在左侧，各文件选择状态保持。
- 手动勾选代表项时，删除计划按真实选择执行，不再强制保留代表项。未选文件可作为保留项继续核验。默认自动清理接口仍保留至少一份。
- 手动选择整组时，确认框显示将有多少组不保留任何文件，并要求勾选“我确认删除这些组的全部文件”。服务端验证和后台任务入队同样要求 allowDeleteAll 明确确认，计划仍绑定指纹/选择集合。软件回收站整组删除仍可还原。
- 相似删除的“保留最大文件”为可选项，初始不勾选；开启后，即使最大文件被选中也会保留，并重新计算数量/大小和整组提示。

## 标签与目录

- 标签属性优先显示12种固定色块，“自定义颜色”为可选入口。每个新标签从固定颜色中随机分配一个颜色并保存；多父引用、再次添加、改名和重启均不重分配。已有标签颜色保留；地理自动标签也保留其创建颜色。
- 常规目录行增加“编辑标签”，对该目录及所有子目录中已索引媒体批量新增/移除共同标签。范围包含隐藏、停用目录中的索引，排除回收站和已标记丢失的记录；不扫描磁盘、不修改原文件、不包含仅前缀相同的相邻目录。弹窗写明范围和数量；使用原有最近标签、查询、层级和连续添加交互。
- 目录标签工作沿用持久化后台队列；入队及执行时核对目录范围，任务记录冻结目录、标签动作及每个文件的名称/地址/大小。任务状态改为每页5行；逐文件详情仍按原分页显示。M3历史自动清理与留档仍仅是计划。

## 幻灯片

- Enter切换“全屏幻灯片”开关：首次进入并勾选，再次退出并取消勾选。复选框本身获得焦点时也能使用Enter；输入框、其他下拉和普通浏览的Enter保留原行为。全屏视频进度条避让继续有效。
- 提前准备后3个媒体：照片使用与查看时一致的预览URL并解码；视频使用 preload=metadata，保持暂停、不自动播放。随机播放先排接下来的3项，再按同一队列播放；循环末尾也准备下轮。仅保留当前项和接下来3项的资源引用，离开窗口清理视频资源；预加载失败交给正常查看流程重试，不改变原件。

- 工程与React渲染器类型检查、生产构建通过；9个文件共91项核心测试通过。新增覆盖整组确认、删除代表项、最大文件选项、回收站恢复、固定颜色持久化、普通/智能相册与标签全量排序及播放一致性、目录边界/子目录/隐藏/停用/回收站范围。
