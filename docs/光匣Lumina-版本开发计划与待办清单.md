# 光匣 Lumina · 版本开发计划与待办清单

更新日期：2026-10-21。当前程序基线：**M2 .4.8.10.2**，数据库schema 10；当前桌面设计书：**0.8.1**，手机设计0.8仍为M4规划。

本文新建为后续开发的待办入口，汇总M2收尾、早期遗留功能和M3–M6范围。M0–M6表示功能里程碑，设计号0.8.1和程序包后缀.4.8.10分别管理。本清单不新定小版本号、发布日期或工期。

状态以当前实现记录和最新用户决定为依据。新增“拖拽复制到外部软件”列为M2收尾，交互已完善并通过隔离回归，真实外部接收仍待验收。本文列出的待办尚未因写入计划而完成开发或测试。

## 1. 当前结论

M2主要整理功能已实现并完成本机回归，包括四种媒体视图、结构化搜索、层级多父标签、普通/智能相册、隐藏与回收站、重复/相似检测、查看器与幻灯片、离线足迹、后台任务、存储统计和缓存清理。

当前可以交付M2核心功能运行包，但完整发布验收尚未结束。最新.4.8.10包含即时任务侧栏、GIF自动播放限制、视频分段暂停续作及外部播放器建议、隐藏同步过滤、扫描与重复检测优化、悬浮信息精简，225项完整测试通过，最终EXE记录见交付文档；此前.4.8.9包含胶片悬停放大及动图/AVI短片预览、时间轴响应、中文错误、GIF自动播放、导入路径记忆与同名确认、标签隐藏例外及Windows属性后台同步、删除反馈与回收站期限、中文输入英文名修复，217项完整自动测试及最终EXE62项检查通过，证据见docs/m2-update-20261021.4.8.9.md；此前启动6项和缓存设置11项证据保留；此前导入与拖出证据保留；此前窗口记录保留，不代表10万真实媒体、外部软件接收、跨电脑和多显示器全部通过。

媒体缓存位置可选择并安全后台移动，现有缓存默认保留原位，仅新装默认软件目录；目录管理集中并每页10条。媒体缓存迁移不等同于SQLite、相册标签等完整用户数据迁移。

另外，完整自定义主题、数据目录迁移、用户数据备份恢复仍是早期M1遗留，不自动改名为M3新增范围。

## 2. M2收尾：功能完善

### M2-F01 拖拽复制到外部软件

**状态：功能实现及本机隔离回归已完成，真实外部接收兼容待验。** 用户本次追加要求：方便将图库媒体拖拽到外部软件使用。

目标交互：

- 从媒体缩略图或已选媒体拖出，支持单张与多选；拖动已选项带出整个选区，拖动未选项以该项为对象。
- 默认表达复制，保留图库原件、索引、标签及相册关系，不把外部拖出变成原文件移动。
- 图库、相册内、标签关联媒体和隐藏内容等可浏览媒体范围，按当前上下文及允许的动作复用拖出能力。回收站等特殊范围不能绕过其文件状态限制。
- 资源管理器、聊天软件、编辑软件按各自接收能力取得原文件或图片；不能承诺所有软件都会以相同方式接收或保留元数据。
- 区分“媒体卡片拖出”和“空白处框选”，不破坏Ctrl/Shift多选、编辑模式、标签层级拖动及正常点击选择。
- 拖出失败、原件不存在或不可读取时给出明确反馈，结束后释放交互状态。

实现与边界：

- 复用已有稳定媒体ID及Windows原文件拖出通道，检查现有入口是否在各浏览范围可触发，不仅验证接口返回了路径。
- 原文件引用可能包含EXIF/GPS。需要脱敏时使用导出副本流程，拖出不暗中改写或替换原件。
- 外部软件对文件大小、数量、编码及图片/文件接收方式的限制单独记录，不将接收端拒绝静默标成成功。

验收清单：

- [x] 单张照片、视频可从卡片发起原生拖出请求，四种视图文件载荷正确。
- [x] 多选拖出保留完整且正确的选区，不误带上一批媒体；失败后可重试。
- [ ] 资源管理器真实落盘复制成功，源文件内容及位置保持不变。
- [ ] 微信等聊天软件真实接收验证，记录其作为图片或文件接收的结果。
- [ ] 选择合适的图片/视频编辑软件验证拖入打开或导入，记录不支持的组合。
- [ ] 非当前选区拖动、框选、Ctrl/Shift、编辑模式与取消拖动不互相冲突。
- [ ] 原件缺失、不可读及接收端取消时正确结束，界面仍可继续使用。

证据见 [M2 .4.8.3交付](output/development/Lumina-m2-next/docs/m2-update-20261020.4.8.3.md)。原件缺失、普通/隐藏范围、回收站禁用和多次触发已通过；真实鼠标拖放因桌面控制授权超时未完成，不能标成接收成功。

本项与下节M2-QA01配套，属于同一拖出能力的功能与兼容验收，不重复统计成两个独立功能。

### M2-F02 本地导入

**状态：.4.8.5已实现并通过本机隔离验收。** 支持多个文件/文件夹拖入、Ctrl+V文件和剪贴板图片、路径确认和“不再提示”、常规导入设置与批量文件夹选择。复制保留来源，递归保持层级，同名同内容复用、不同内容自动改名，后台进度/暂停/取消/恢复/重试/重启继续和增量索引均已接入。原生剪贴板及不同来源应用的真实兼容，仍需在M2-QA01补充，不能等同窗口测试中读取器返回测试素材已覆盖全部系统场景。

见 [M2 .4.8.5交付](output/development/Lumina-m2-next/docs/m2-update-20261020.4.8.5.md)。

5. M5按公网和媒体格式专项推进；M6在范围细化后另行立项。
