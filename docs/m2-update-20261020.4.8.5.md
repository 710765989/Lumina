# M2 .4.8.5 本地媒体导入

日期：2026-10-20。基于.4.8.4，桌面设计0.8.1和数据库schema8不升版。

- “暂无标签”改为深灰蓝文字、浅色底和细边框的10px胶囊，在默认/时间/瀑布/列表及共用媒体视图中保持可读。
- 图库标题区增加“＋ 导入”。可选择多个本地媒体文件；可将文件或文件夹拖入窗口；在非输入框区域按Ctrl+V，或在常规点击“粘贴导入”，可粘贴资源管理器复制的文件和剪贴板图片。只复制，不执行剪贴板文本，不按剪贴板剪切标记移动原件。
- 首次导入弹出路径确认，显示媒体数、大小、前5个名称和跳过数量。可填写完整路径或选择文件夹；勾选“不再提示，以后都导入到这个路径下”后保存路径并跳过后续确认。路径失效时回到确认页。普通输入框中的粘贴不触发导入。
- 常规顶部增加“导入设置”：默认路径、是否提示、保存设置，以及导入文件/批量导入文件夹/粘贴导入。选择多个文件夹后递归复制照片和视频，保留顶层名称及子目录层级，过滤非媒体与目录链接。
- 同名同内容复用已有文件；同名不同内容以“ (1)”等后缀改名，不覆盖。禁止导入到来源自身或来源目录内部，拒绝目录链接、缓存目录及已停用图库目标。
- 导入前冻结预览计划（10分钟有效），开始后保存一条聚合任务及逐文件来源路径、名称、大小、目标、结果/失败原因，防重复提交。后台复制并校验内容，使用临时目录完成后发布；媒体文件保留来源修改时间。
- 复用任务状态与右下角进度/成功提示，支持暂停、取消、恢复、仅重试失败项及重启后继续；取消保留已完成副本，未完成项可恢复。已完成项不会重复复制。进度详情区分复制校验和建立索引。
- 导入后对本次输出文件进行增量索引，不扫描目标目录已有的无关文件；自动纳入已有启用图库根，或新增该导入目录作为图库。目录标签/相册规则继续通过现有索引链路生效。
- 剪贴板图片保存为应用生成的临时PNG。取消预览及成功导入后清理应用自己的暂存图片；已开始但暂停/失败/取消的任务保留来源以支持恢复。真实用户文件不会按暂存图片策略删除。

验证：工程及React渲染器严格类型检查、生产构建通过；172项完整自动测试全部通过，新增7项导入测试覆盖复制不覆盖/原件保护、递归/增量索引、重复提交、取消恢复、失败重试、目录链接与停用目标、重开数据库恢复、仅清理应用生成的剪贴板文件。冻结EXE通过12项导入窗口检查和15项拖出回归，共27项；“暂无标签”、导入确认和常规设置已截图检查。

验证边界：文件拖入用Chromium真实File对象经过生产webUtils/preload取得本地路径，选择器和剪贴板读取在窗口测试中返回隔离素材，未读取或改写用户剪贴板，未声称已覆盖所有外部应用的真实复制/粘贴。微信/资源管理器实际拖出接收、干净虚拟机、真实十万媒体与多显示器出口仍待验。全部测试不使用用户图库和数据库。

证据：工作区output/audit/m2-media-import-20261020/validation.json、tests.json，以及tmp/qa对应测试目录。运行包：release-m2-20261018.4.8.5/win-unpacked/Lumina.exe。本轮不commit/push。
