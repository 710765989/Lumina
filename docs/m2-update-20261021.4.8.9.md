# M2 .4.8.9 浏览预览、隐藏与导入修复

日期：2026-10-21。分支 feature/M2；设计保持0.8.1，数据库由schema9升级到10，升级前自动保存一致备份，软件名称不变。

- 胶片悬停220ms后在当前缩略图正上方显示放大预览，保持原比例；两端自动避让窗口边缘，位于查看器全屏层内。静态图复用唯一640px缩略图；动图播放原动画；视频生成并复用前6秒、最长边宽480px、15fps的静音MP4。只允许一个短片生成/播放，移开/滚动/失焦/切换媒体/改变全屏后关闭；离开取消未完成生成并移除临时文件。短片生成限2线程、15秒超时；失败保留静态预览。短片纳入缓存分布、迁移与永久删除回收，不生成第二套静态缩略图。
- AVI完整播放仍需第一次整段转H.264/AAC MP4，转完才播放，长片需要较长时间；复用未变更文件的兼容缓存。胶片悬停不触发这类整段转码。
- 相册路径省略菜单适配名称宽度，上限480px及视口，保留键盘、Esc及外部焦点关闭。媒体完整提示增加大小；普通网格信息区34px/悬停48px，回收站常显52px/悬停66px，底部期限为高对比蓝色徽标。标签区域不加内部滚动。
- 长搜索胶囊最大260px，省略文字、固定删除按钮，悬停完整值；图库与集合共用，不截断实际查询。
- 时间轴立即目标月份/骨架，120ms拖动防抖、松手立即提交。复用聚合计数、日期边界索引取首60项；单请求在途，待处理仅留最新，忽略过时结果。最近6个月份窗口内存复用，过滤、排序及图库变更后失效，上下仍可继续浏览完整范围。
- 用户可见错误中文化，包括HEIF、权限、文件不存在、空间、数据库、超时及未知异常；去IPC包装/堆栈，原始诊断保留日志。本轮没有新增HEIF解码器。
- 旧索引GIF缺宽高/帧数时，可见区域按需补全并保存，最多2并行、合并同项读取，内存256项，不重新扫盘。自动播放继续受≤2MiB、同屏8项、单项估算解码≤32MiB/合计≤128MiB限制，不满足预算仅悬停播放。
- 导入每次接受有效路径都会记住，未勾“不再提示”也预填但仍要求确认；取消/无效目标不改变记忆。同名增加保留两者（默认）、跳过、覆盖三策略；跳过普通确认时仍显示冲突确认。覆盖按钮明确不可撤销，冻结目标指纹、复制校验后替换，确认后被改的目标保留并报告失败。任务详情区分已跳过并记录策略。
- 标签规则造成隐藏时，取消隐藏先列出实际原因，提供仅显示此项/显示所选项、编辑标签及取消。例外仅针对已确认的隐藏标签，保留关联；新隐藏标签继续生效，不绕过停用目录或回收站。再次手动隐藏清除该媒体例外，标签解除隐藏时清除其例外。
- 单张隐藏/取消隐藏立即反馈，统计只对受影响媒体增量更新；标签规则只重算其关联媒体，不再阻塞全库统计。同步Windows属性开启后，手动/有效标签隐藏都入持久后台队列；保留原Hidden位及其他属性，最后一个隐藏原因解除后恢复，后续标签关联和层级变化同样生效。复用PowerShell助手，不为每文件重复启动。任务可查看/暂停/取消，取消不回滚已完成项。仅改Hidden位不触发新扫描。
- 删除确认在文件操作完成后立即关闭，列表立即移除成功项，不等待无关全页刷新。回收站剩余天数固定显示蓝底深蓝字徽标。
- 中文输入法预编辑阶段不再把拼音复制到英文名；提交中文清除自动填入值，纯英文继续自动复制，手填或原有英文值保留。此前已保存错误英文名需手动编辑，不擅自清空。
