# M2 .4.8.10.10 动画开关生效与高DPI图标

日期：2026-10-21。

## 动画不显示的原因与修复

已通过只读进程检查确认用户运行 .4.8.10.9，并通过 Windows SystemParametersInfo(SPI_GETCLIENTAREAANIMATION) 确认系统客户区动画关闭。旧版本无条件遵守 prefers-reduced-motion，导致软件内手动开启动画仍被覆盖；原隔离验收固定了 no-preference，漏测“系统关闭、软件明确开启”的组合。

偏好顺序改为：软件内显式 on/off 优先，未设置时跟随系统。界面勾选状态、布局弹簧、节点保留和CSS悬停过渡使用统一的有效状态。监听系统偏好变化及跨窗口设置变化。默认尊重系统减少动态效果，用户可通过“界面动画”明确开启本应用动画；不修改 Windows 设置。说明文字同步交代优先级。

## 图标清晰度

启动窗此前用32×32图显示42 CSS像素，高DPI下需要更多真实像素；用户当前屏幕缩放175%，需要约73.5像素。改用现有256×256透明PNG，启动框显示尺寸仍为42 CSS像素，主界面28 CSS像素；BrowserWindow也改用高清素材。EXE ICO资源及品牌图案保持原样。素材直接取已有高清导出，不放大32像素小图。

- 最终EXE独立数据库7项验收通过：系统减少动态效果下显式开启仍有连续缩放和悬停动画、重开持久化、显式关闭、默认跟随、顶栏256像素图片、高DPI启动框。启动模块从最终app.asar提取，适配为测试加载格式后在同一Electron进程中打开，使用原生窗口截图核对100%/150%/200%等效像素密度，图案边缘完整清晰。
