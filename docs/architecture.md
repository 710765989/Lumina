# Lumina 架构基线

Lumina 采用 Electron + React + TypeScript + Vite 的桌面应用架构。pnpm workspace 将契约、存储、核心服务和宿主进程拆成独立包，便于后续接入桌面端和手机端客户端。

## 运行边界

- `apps/core-host`：核心进程入口，负责启动数据库和核心服务。
- `packages/core`：目录扫描、媒体识别、任务编排和业务用例。
- `packages/storage`：SQLite 连接、迁移、索引和领域数据读写。
- `packages/contracts`：跨进程调用使用的 Zod 契约、媒体类型、任务状态和错误码。

## 数据边界

SQLite 是本地唯一事实源。媒体文件保留在用户自己的目录中，数据库只保存路径、稳定媒体 ID、文件指纹、相册引用、标签和任务状态。相册是引用关系，删除相册不会删除媒体文件。

扫描使用稳定的“路径 ID”和独立文件指纹：路径 ID 让重复扫描更新同一条记录，指纹用于判断文件内容或元数据是否变化。媒体搜索使用 SQLite FTS5，默认隐藏媒体不出现在普通浏览和搜索结果中。

## 阶段边界

M0 先验证原生依赖、SQLite、媒体链路和任务状态；M1 实现单机本地图库的目录、索引、普通相册、标签、搜索和隐藏基础能力。账号、私有相册、加密、手机上传、分享和智能相册计算在后续阶段设计和实现。
