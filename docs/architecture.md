# Lumina 架构基线

Lumina 采用 Electron + React + TypeScript + Vite 的桌面应用架构。pnpm workspace 将契约、存储、核心服务和宿主进程拆成独立包，便于后续接入桌面端和手机端客户端。

## 运行边界

- `apps/core-host`：核心进程入口，负责启动数据库和核心服务。
- `packages/core`：目录扫描、媒体识别、任务编排和业务用例。
- `packages/storage`：SQLite 连接、迁移、索引和领域数据读写。
- `packages/contracts`：跨进程调用使用的 Zod 契约、媒体类型、任务状态和错误码。

## 数据边界

SQLite 是本地唯一事实源。媒体文件保留在用户自己的目录中，数据库只保存路径、稳定媒体 ID、文件指纹、相册引用、标签和任务状态。相册是引用关系，删除相册不会删除媒体文件。

扫描使用稳定的“路径 ID”和独立文件指纹：路径 ID 让重复扫描更新同一条记录，指纹用于判断文件内容或元数据是否变化。媒体搜索使用 SQLite FTS5，默认隐藏媒体不出现在普通浏览和搜索结果中。

## 阶段边界

M0 先验证原生依赖、SQLite、媒体链路和任务状态；M1 实现单机本地图库的目录、索引、普通相册、标签、搜索和隐藏基础能力。账号、私有相册、加密、手机上传、分享和智能相册计算在后续阶段设计和实现。


M3开发前必读：[任务履历、自动清理与留档](m3-task-history.md)。7天历史清理、留档开关、最近一次/多次、自定义目录/文件名与读取任意履历均待M3；当前仅完善任务与文件明细，不执行自动清理。


## 2026-10-19 标签关系与浏览定位补充

schema 7中tags仍是唯一标签实体（名称、英文名各一份），tag_edges(parent_id,child_id)单独记录多父引用。所有路径必须无环且最多5级；操作在事务中校验。递归祖先查询用UNION去重，避免菱形引用重复统计。媒体直接标签与自动祖先来源继续分开，引用改变仅重算受影响媒体。删除引用不删除实体；全局删除说明全部影响，共享后代不会被独有分支级联误删。

双语名称目前手动输入，英文复制规则与显示/拼音匹配由统一辅助函数实现；未引入翻译模型或联网服务。搜索顺序独立持久化，默认最近选择，按名称时层级顺序跟随父标签。子菜单以标签ID连接实体，避免创建重复标签。

整库时间轴返回按月聚合，不返回全量媒体。月份定位使用完整查询中的分页偏移，初取目标200项；向上补前页并保留可见媒体锚点，向下加载后页，保持完整筛选范围、虚拟渲染和按需取图；Ctrl+Shift全前/全后仅取当前筛选的稳定ID。网格缩放以可见媒体ID为锚点；编辑模式的框选/键盘范围按手势开始时的选区做反选。任务快照记录冻结文件路径/大小及标签动作，历史清理留档仍归M3。


M2 .4.3增量：相册/标签查询与播放列表共用SQL排序，标签颜色由统一12色调色板在首次创建时随机持久化。目录标签队列显式携带rootId，入队及逐项执行核对目录边界，可处理隐藏/停用目录中的索引，排除回收站和丢失记录。整组删除计划返回emptyGroups，服务端及队列入队要求allowDeleteAll确认；仍有保留项的组沿用原件核验。幻灯片维护最多后3项的预加载队列，照片解码、视频元信息预载；随机播放消费同一队列，退出清理资源。任务列表每页5行，文件快照详情分页不变。


## M2 .4.4 目录规则与分层相册

schema 8新增directory_settings、directory_rules、directory_edges、directory_media_tags、directory_albums、directory_album_media及albums.parent_id。升级前保存一致数据库快照。标签实体仍唯一，目录规则建立最近已配置祖先的引用，最多5级，事务拒绝环。规则拥有的引用与媒体标签来源分别记录，修改只撤销其拥有的关联，手动标签与相册成员保留。重叠图库移除一方时，其他图库覆盖的媒体ID和手动整理信息保留，并更新剩余规则。

roots.preview只读取目录与最多12个小预览，不登记图库；roots.configure验证预览内目录，保存设置并启动持久化directory-rules任务。目录规则按实际路径索引，每文件向上找祖先，避免逐项扫描所有规则。扫描、递归监听、重命名和回收站恢复均调用同一入口。恢复整理可重复校验，操作幂等；取消停止本次追赶任务，不撤销已保存规则。任务快照保留当时规则及逐文件路径/大小。

自动相册稳定绑定rootId+relativePath，以parent_id形成层级；父相册递归包含后代媒体。预先创建空目录相册，监听到新目录媒体时补建。关闭自动或层级更新时保留已有相册和内容。相册层级不受标签5级上限影响。

主页视图一次性迁移至immersive，之后记忆用户选择。TimelineGrid只批量请求可见媒体标签，每次最多300项并缓存，文件变更与标签版本变化后失效。灰色半透明覆盖层占卡片底部30%，目录标签优先且带文件夹标识，不改变媒体框尺寸。局部标签祖先继承以受影响媒体作递归起点，避免每文件展开全标签图。


## M2 .4.6 共享视图和集合搜索

默认/时间/列表统一使用TimelineGrid。网格间距8px，列表行76px、行距4px。默认与时间视图使用同一浅灰半透明悬浮信息，常规高度30%、小卡片最少60px，紧凑文件名与药丸标签；目录标签优先。标签区不提供滚动。列表照片使用contain完整显示，加载/重试占位也限制在行内。可见区最多300项标签查询推广至所有视图，继续缓存与按变更失效。

CollectionMediaView加入独立CollectionSearch，文件名/标签/标签排除/无标签与主页复用同一SQL筛选语义；数据库用albumId/tagId约束集合后计数、分页、排序，播放列表使用同一过滤条件。普通相册引用、智能相册规则与标签祖先匹配不改变，不在前端只筛已加载200项。局部查询状态留在对应浏览页，切换集合时清空；侧栏跨页返回保留当前搜索，点击当前侧栏首页后重新进入为新查询。视图设置和上一个网格模式分开记忆，缩小到列表后放大恢复原模式。

albumSummary仅在智能相册可见数为0时追加LIMIT 1存在性检查；匹配媒体存在但因隐藏/停用/黑名单等全部不可见，返回hiddenByVisibility。相册浏览层隐藏卡片与数量，保留实体、规则和手动封面。恢复可见后重新展示。真正无匹配的空智能相册仍能编辑，普通相册不自动隐藏。

主进程在userData/window-state.json保存normal bounds和maximized。尺寸和位置变化合并写入，关闭前刷新；忽略最小化/全屏/跨屏幻灯片临时位置。启动时按当前屏幕工作区校验、钳制边界，断开显示器时回到可见区域，兼容小屏；Windows高DPI创建后以测量值校准，避免反复重启尺寸累积增长。


## M2 .4.7 浏览器资源与菜单

MediaViewer铺满客户区；原全屏幻灯片状态合并为标准Fullscreen API状态，Enter统一切换。全屏隐藏/边缘显示共用同一逻辑，原生视频进度条避让保留。ViewerContextMenu挂在全屏元素内，工具动作复用现有处理器；需要应用级模态框的动作先退出全屏，避免全屏层遮住兄弟模态框。

ViewerFilmstrip使用usePlayback的完整ID序列，横向虚拟可见区+4项余量，仅为窗口内记录请求缩略图。记录请求分批最多31项，缓存裁剪至可见窗口，异步失效不覆盖后续窗口。导航仍由usePlayback以稳定ID读取，滚动胶片独立于图库分页和舞台媒体。悬停视频延迟450ms，仅一个网格活动项，离开/失焦/操作/卸载释放src；不预先给所有视频创建播放器。

TimelineGrid网格间距4px、列表行距2px，浅灰信息背景alpha 0.64，悬停缩放只变换图像。尺寸/视图切换对可见卡片使用180ms FLIP过渡并尊重prefers-reduced-motion，不对整个三万项图库建动画。分页使用同步更新的绝对end游标并按ID去重，避免状态尚未提交时重复读写同页。

SearchTypeMenu为主页及CollectionSearch共用二级类型选择器，标签条件包含/排除映射现有tagNames/excludeTagNames，有/无映射excludeUntagged/untaggedOnly。标签语义不变。文件名不包含映射excludeFileNames（与原文件名子串/拼音匹配互为反向），文件格式映射extensions；查询使用最后后缀等值比较，多个后缀OR，不使用第一个点切割。所有媒体查询、统计、时间轴与播放列表共享同一参数验证及where构造，避免只过滤已加载200项。后缀/文件名包含式条件可能扫描候选集合，不引入新schema。AlbumEditor默认智能，通过互斥选项折叠规则或普通相册标签，排除标签单独details；仅保存当前类型，现有相册不转换类型。


useAppNavigation维护100条应用内历史，通过各页usePageLocation读取/恢复局部位置；侧栏行为仍独立。Windows app-command与DOM侧键有180ms跨来源去重，F5在before-input-event阻止浏览器原生重载，再派发数据刷新。编辑模态框阻止导航；查看器处理前后媒体及当前预览刷新。

useWindowControlColors在右上角采样DOM背景层，合成透明遮罩颜色；MutationObserver变更合并到requestAnimationFrame，仅颜色变化发送受十六进制验证的window-controls-style IPC。主进程仅setTitleBarOverlay，不禁用系统按钮。查看器Escape追踪仍独立于颜色，避免普通弹窗影响视频Esc。普通相册标签由applyOrdinaryAlbumTags在保存、手动加入与目录自动加入入口增量补齐，不在解绑时删除媒体标签。


## M2 .4.8 浏览资源与扫描

TimelineGrid按稳定媒体ID扁平挂载绝对定位卡片，布局计算仍按行/瀑布列虚拟化。动画仅在视图/尺寸变化测量，普通滚动使用rAF和窗口分段更新。单一640边界缩略图缓存与UI尺寸无关；版本URL保留浏览器缓存，后端stat检测后复用已验证JPEG。过时指纹/规格只清理缓存。useUiMotion持久化本机动画偏好。

hiddenOnly通过共享SQL过滤器贯穿搜索/统计/月份/播放列表，includeHidden的记录读取仍校验缺失、停用目录和回收站，避免越过有效图库范围。隐藏页复用CollectionMediaView，选择来源附在时间网格，整月选择使用服务端本地时间边界查询ID。标签编辑/显式隐藏导出允许处理有效隐藏媒体，移除规则仍由标签属性管理。

RootWatcher合并监听事件并限制每root启动频率，忽略缓存/不相关内容。performScanDirectory先按指纹排除未改变文件，纯空事件不写tasks、不推送库变更；删除只对missing实际变化通知。任务取消以任务状态为准，缩略图完成不会覆盖已取消，FFmpeg支持AbortSignal并等待child close。取消保留已完成结果。prune-release-packages严格验证包路径/内容，仅保留两版，不清用户媒体和数据库。

## M2 .4.8.1 目录设置与浏览

目录预览区分索引来源和显式磁盘来源；已知空目录路径快照写入settings，以rootId绑定并在移除目录时清除，无schema迁移。已有目录configure比较规范化规则，改名/无变化直接返回；变更只创建apply阶段的持久任务。首次导入创建scan阶段任务。实际扫描仍由增量监听或显式重新扫描负责。

任务历史清理在LibraryService聚合扫描、目录、批处理、缩略图和转换的活动状态；只删除确认集合中仍处于终态且没有活动线程的记录，job_items级联删除。刷新后的缩略图批次不引用已清理任务。动图使用共享IntersectionObserver，2MiB/8项和按宽高帧数估算128MiB总预算分配自动播放名额，静态缩略图节点不替换。浏览器历史包含当前媒体查看器快照，切换媒体更新当前项，Back/Forward恢复页面与查看器。TimelineGrid允许内容区左右留白开启框选，并在host捕获拖动后的点击，避免选区被空白点击立即清除。

删除成功或在卷可用时确认ENOENT后，媒体与搜索索引事务清除，settings持久化cache-cleanup队列；预览文件所有权通过media-cache登记，缩略图通过共享的按媒体ID文件名索引定向回收。关闭数据库后不再写队列，重新启动继续，正常软件回收站保留缓存。回收站使用TimelineGrid和MediaViewToolbar，默认list，trash.list与trash.ids共享白名单SQL排序；月份选择独立查询整个回收站时间范围，不局限当前分页。

## M2 .4.8.10 响应与资源约束

CompatibilityVideos把完整兼容视频拆为10秒可重用片段，检查点存在video-preview任务payload（媒体ID/指纹/进度/相对片段名），片段纳入media-cache与cache_inventory。准备启动串行化、同一媒体请求合并、仅一个完整视频编码在途；暂停立即Abort当前子进程，保留已完成片段，下次按相对缓存路径校验并继续。缓存被显式清理时从完整前缀恢复或重建，完成原子提交MP4并移除片段。会话token防止旧查看器关闭回调暂停新会话；8秒慢加载提示可打开系统默认播放器，交接先停止内部准备。悬停视频统一使用独立6秒静音缓存。

GIF偏好保存于本机localStorage并即时发布更新，大小上限512KB–10MB、数量1–16，仍受32MiB单项/128MiB总解码预算约束。Windows同步建任务前比较有效目标隐藏状态与此前应用状态，剔除无效候选。TaskDrawer直接复用分页任务组件，立即绘制缓存/骨架，避开通用设置和缓存统计加载。

扫描使用复用SQL、1秒通知节流及既有受限读取。OrganizationJobs合并相同活动检测范围；重复检测命中hash_fingerprint时复用SHA256，未命中才按可取消流读取。相似特征改文件输入而非整文件JS Buffer，显式关闭Vips文件缓存，避免Windows源文件句柄被持有。

## M2 .4.8.10.2 GIF逐帧自动预览

自动播放使用ImageDecoder逐帧输出并及时关闭VideoFrame，画布最大480×320，保留唯一静态缩略图。压缩输入按实际读取长度限额，取消时Abort读取、清除计时器、关闭解码器和画布，晚到帧也释放；失败后释放自动播放名额。调度预留使用压缩输入/解码数据、源图工作缓冲及画布的估算，不按全部帧数乘算；继续执行32MiB单项/128MiB合计估算预算。该预算不等同进程RSS硬上限。用户文件大小/数量设置沿用，手动悬停仍可播放原动图。没有新扫盘或新增动画缓存文件，后端与schema不变。
