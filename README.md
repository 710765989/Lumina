# 光匣 Lumina

**让散落在文件夹里的照片、视频和参考图，更容易找到、整理和使用。**

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

<img src="apps/desktop/renderer/public/lumina-album-icon-256.png" width="80" alt="光匣 Lumina 相册图标">

Lumina 是一款 **Windows 本地照片与视频管理器**。把已有文件夹加入图库，就能集中浏览、组合搜索、打标签、建相册，以及对比重复和相似照片。无需注册账号，日常整理可以离线完成。

**正式版 1.0.0 · Windows 10 / 11 x64 · 简体中文、英语、日语**

[下载安装包与免安装版](https://github.com/710765989/Lumina/releases/tag/v1.0.0) · [详细使用说明](docs/user-guide.md) · [反馈问题](https://github.com/710765989/Lumina/issues)

## 它有什么不一样？

**保留现有文件夹，多一种找图方式。** 不用先把全部照片搬进专用图库。添加目录时，Lumina 记录文件位置并生成浏览缓存，原文件仍在你选定的目录。多个目录可以放在一起看，也能用时间轴快速回到某个月。

**一张图可以有多个分类，不必为了分类复制文件。** 海边照片可以同时属于“旅行”“风景”和“壁纸”。给它添加多个标签，或放进多个相册，引用的还是同一份文件。标签支持最多五级层级和多个父标签，适合不断扩大的参考素材库。

**经常要做的分类，可以交给规则。** 创建一个包含“旅行”和“风景”的智能相册，以后给其他照片加上对应标签，它们就会自动出现。目录标签还可以让目录及子目录中的媒体继承分类，后续新增文件也能沿用。

**清理前能对比，找到了就能拿去用。** 完全重复和视觉相似分开查看，左右对比后再决定保留哪张；删除前显示数量和大小。挑好的素材可以直接拖到支持文件拖放的外部软件，减少再次打开资源管理器找文件的步骤。

## 哪些时候会用得上？

| 你的情况 | 可以这样用 |
| --- | --- |
| 照片散落在年份、设备和备份目录里 | 加入同一个图库，按时间集中浏览 |
| 同一素材既是“人物”，又是“构图参考” | 加多个标签，用多个入口找到同一原件 |
| 每次都要找某一类图片 | 建立按标签规则更新的智能相册 |
| 想清理导出版本、备份和连拍 | 先查重复与相似，对比后勾选删除 |
| 找图后还要交给其他软件使用 | 拖出文件，或在资源管理器中定位 |
| 不想上传整个私人图库 | 本地建立索引和缓存，无需云端账号 |

## 五分钟开始使用

1. **添加目录**：进入「常规 → 目录设置」，选择已有照片或视频文件夹。
2. **确认缓存位置**：首次添加时选择缓存目录，再开始扫描。空间充足时可放在固态硬盘上。
3. **集中浏览**：在「图库」试试时间轴、搜索和右键菜单。
4. **试一次分类**：选几张照片，添加标签，再建立普通相册或智能相册。
5. **查看后台进度**：大量操作可在右上角任务入口或常规设置中查看进度与结果。

**添加已有目录主要建立索引；“导入”会把文件复制到你确认的目标目录。** 导入支持拖入、粘贴和批量文件夹，同名文件按提示处理。

## 关于文件和数据，先知道这几件事

- **原件、整理信息、缓存是三回事。** 原件在媒体目录；标签、相册和索引在本机数据库；缩略图和兼容预览属于缓存。缓存可重新生成，整理数据库需要备份。
- **本地整理不等于自动备份。** 软件不会替你备份原照片，也不会因建立图库就自动删除重复文件。
- **隐藏不是加密。** 软件隐藏和可选的 Windows 隐藏属性只控制可见性，不能代替密码和加密保险箱。
- **相似结果由你判断。** 从普通相册“移出”只改变相册关系；删除媒体会进入文件删除流程。永久删除不可恢复。
- **扩展名不保证能播放。** 部分 HEIF、AVI 或特殊编码可能不受支持，或需要较长的兼容预览准备时间，可改用外部查看器或播放器。WebM 按视频处理。

数据库和缓存的实际路径请在「常规 → 缓存设置」查看。免安装版也使用当前用户的应用数据目录；**复制程序文件夹不等于迁移全部整理信息**。升级前先关闭软件，备份原件和用户数据。卸载默认保留用户数据库；外部缓存保留，安装目录内缓存可能随程序目录删除。[完整数据与缓存说明](docs/user-guide.md)

Lumina 专注于本地整理与浏览，不提供专业修图、云备份、团队协作、加密保险箱、人脸识别或图片内容语义搜索。日语词典生成读音，**不翻译标签**。性能取决于硬盘、编码、图库大小和播放设置；跨应用、跨机器及超大真实图库的持续兼容测试见[验收记录](docs/m2-acceptance.md)。

## 想看代码或自己构建？

需要 Windows x64、Node.js 22.13 或更高版本、pnpm 11.25.0。原生依赖缺少预编译包时，还需要 Python 和 Visual Studio C++ Build Tools。

```powershell
corepack enable
corepack prepare pnpm@11.25.0 --activate
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm --filter @lumina/desktop dev
```

制作运行包用 `pnpm --filter @lumina/desktop package:zip`，安装包用 `package:installer`；结果位于 `apps/desktop/release/`。首次构建需联网下载依赖，日常使用可离线。仓库和源码 ZIP 排除个人图库、数据库、缓存、日志及凭据。

项目尚未选择项目级源码许可证；可以查看源码不等于已授予开源使用许可。第三方组件保留各自的许可证与署名，见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
